# P16 Ruleset v2 — Repaired After Adversarial Refutation Pass

## Cover

**What this is.** This is the Phase-3 repair of `merged-ruleset.md` (the Phase-2 judge-and-merge of three candidate lenses). A fourth adversarial pass ran every rule in the merged ruleset through two additional lenses — **authority** (does the rule actually match settled Owner law, accepted code, and package boundaries?) and **exploit** (can a rational player or AI break the rule as written?) — and produced 70 verdicts. This document applies the smallest correction for every verdict judged a valid refutation, states why every other verdict was rejected, and carries forward everything from `merged-ruleset.md` that no verdict touched. **No Owner-selected direction from assignment §2 is reopened.** Where a valid refutation showed a selected rule was structurally impossible or self-contradictory as written, the correction keeps the Owner's intent and states the smallest textual fix, flagging a new Owner decision only where the gap cannot be closed by drafting alone.

**What changed, in one paragraph.** Four rules had severe defects requiring real correction: R04 conflated three distinct sale-restriction conditions into one and left R2 sale unrestricted during an active theatrical run (split into R04a/b/c); R05/R03 left the founding rights-holder undefined for historical/orphan IP, enabling a free land-grab (fixed by an explicit founding-holder rule); R09's competing-bid escape hatch had no defined mechanism anywhere outside bankruptcy, leaving it either dead language or a silent bankruptcy-mechanism leak into R08's holdback cap (fixed by precedence + scoping); and R28's literal "no isPlayer exemption" text, read alone, would reopen the single most-hated failure mode found in the whole research program — a rival buying the player (fixed by an inline carve-out to R16). A further ~20 rules had moderate gaps (double counting, cash-netting arithmetic, an unbounded flip-arbitrage window, an unnamed inbound-licence case, an unscoped headcount cap, a wait-forever bankruptcy incentive, and others) and ~15 had minor documentation/citation gaps. Everything is listed in the Repair Log (§22) with the verdict it answers. Two refutations were rejected outright as invalid (each merely preferred another game's mechanic with no code, law, or exploit backing it); the rest of the "rejected" verdicts had severity **none** — the challenge was tried and did not land.

**Numbering discipline.** Rule IDs are stable. Only R04 was split (into R04a/R04b/R04c, its unrelated R4-forbidden-until-P18 clause folded into R02 where R4 is actually defined) because the authority refutation showed it was doing three distinct jobs under one label. R32 was **not** split — the correction that would have split it (P16A frequency-guard vs. P16C migration-honesty guard) is instead applied as a package_owner relabel to "P16A/P16C" per the refutation's own stated alternative, keeping the rule list at 34 entries.

## 3. StoryProperty and minimal-rights model

*(Unchanged from merged-ruleset.md §3 except where noted; full prose retained for reference — see R01–R05 in the Rule List for the authoritative, corrected text.)*

A released Film and its underlying Story Property are two different things (10-rights-law.md, U.S. Copyright Office Circular 14, HIGH/CONFIRMED). `FilmIdentity.studioId` means *creator*, never *current owner* (04-code-audit.md, HIGH/CONFIRMED). Origin is anchored on the existing `isOriginalScreenplay`/`origin:'original'|'pool'` seam (04-code-audit.md, `screenplay.ts:305-345`).

**Correction (R01, authority-minor).** For pool/externally-sourced material there is no author entity in accepted code (`writerId=null`). R01 now states explicitly that for pool-origin properties, the immutable "creator" field records the **greenlighting studio as first rights holder** via the existing pool-purchase fee — an initial-holder fact, not an authorship claim. True external-source/author representation stays the already-logged open question (10-rights-law.md §5.5); this rule does not silently resolve it.

**Correction (R01, exploit-minor).** Greenlighting a production under an owned or **licensed** R3 continuation authority does not mint a new StoryProperty — the resulting FilmId is appended to the parent property's `works[]` list instead, and R1/R3 holdership is unaffected. Without this, a studio could launder a one-time R3 licence fee into permanent, wholly-owned R1 by simply greenlighting the sequel it was only licensed to make.

**Mint point: at Greenlight**, atomically with the property's own first `ownershipEvents` row (correction, R05 authority-minor — see below). INFERENCE, not settled; remaining uncertainty (§21).

**Minimal rights bundle — four kinds, one instrument** (unchanged, R02):

| Right | Covers | Transferable? |
|---|---|---|
| **R1 PROPERTY** | The underlying Story Property, including inherent continuation authority | Sellable, single holder |
| **R2 FILM/LIBRARY** | One released work, tradeable independently of R1 | Sellable, single holder, separable from R1 |
| **R3 CONTINUATION** | Sequel/remake/spinoff authority licensed *out* of R1 | Licensable only, never sold apart from R1 |
| **R4 CROSS-MEDIA** | Future television/cross-media, execution owned by P18 | Licensable only, **forbidden to grant before P18 exists** (moved here from the old R04 — R4's own constraint belongs with R4's own definition, not buried in the sale-restriction rule) |

**Correction (R03, authority-minor).** The single-holder-now `ownershipEvents` ledger design does **not** foreclose a later P16D multi-share/co-finance extension under P12 §32's reserved room ("room for one film to have multiple future ownership/finance shares without changing its identity"). Shares are simply not modeled in P16A–C; this is a v1 policy choice compatible with that reserved room, not a permanent architectural law.

**Correction (R03, exploit-moderate).** R03's rejection rule was scoped only to ownership transfers (R1/R2), leaving no symmetric guard against **duplicate exclusive Licence issuance** — a studio double-optioning the same continuation right to two buyers. New sibling clause: a new exclusive Licence grant over a facet (R3 or R4) is rejected outright if an active, unexpired, non-reverted exclusive grant already exists over that same facet.

**Correction (R04, authority-severe → structural).** R04's own cited source (10-rights-law.md §4.6) names **three** distinct guard conditions; the merged text collapsed them into one, leaving **no restriction on selling R2 while its own TheatricalRun is still paying out** — a studio could sell a still-earning film, pocket the price, and leave an undefined claim on the remaining scheduled receipts. **Smallest correction: split R04 into three explicit rules (R04a/b/c)** — see Rule List. This is a genuine structural problem (§23, item 1), not a wording nit.

**Correction (R05, authority-minor + exploit-severe).** Two fixes to R05: (1) the StoryProperty mint and its **first** `ownershipEvents` row are now stated as one atomic write at Greenlight — only the *second and later* rows append lazily "at first purchase or transaction," resolving an ambiguity against R01's/R03's own invariants. (2) The lazy-mint design never stated who the founding holder is for a property backfilled for a **pre-existing, pre-P16 historical film**, especially one whose studio is already `closed`. Left open, this is a free "orphan-IP land grab": trigger the first transaction on an old, unclaimed title and become its owner for nothing. **Smallest correction:** the founding entry always assigns the historical creator studio as initial holder regardless of its current status; if that studio is closed with no successor, the property is **estate-held/unclaimed** and can change hands only through the same §2.M distressed-acquisition machinery as any other closed studio's assets — never a free claim by whoever transacts first. This is a genuine structural problem (§23, item 4) tied to Owner Decision #1's scope (§20).

**Exploit guards, unchanged and reaffirmed:** single holder + append-only log (R03); rights-in-use lock, now three explicit conditions (R04a/b/c).

**Structural note (R32, package_owner corrected — see §18/§23 item 5).** Row creation stays lazy; a per-asset minimum inter-transaction interval is added (R32) so a legitimately low-value but endlessly repeated trade of the same property across rotating counterparties cannot grow the ledger without bound.

## 4. Film-library value

Unchanged core rule (R06), with one arithmetic correction.

**Correction (R06, exploit-moderate).** R06's own counting clause ("count each owned R1 once, each owned R2 once, never both toward the same figure") **double-books** the ordinary default case — a studio holding both R1 and R2 for the same film — because dossier 09's own valuation ladder already sets R2 (library rights) to a formula tied to the *same* film's revenue that R1's sequel-potential figure also derives from. **Smallest correction:** when one party co-holds both R1 and R2 for the same film, only the R2/catalog-value lane contributes to Library Valuation; R1's franchise-option premium is added only when R1 is held **apart** from R2 (unproduced/shelved property, or a genuine split-ownership case). This closes a systematic Studio-Valuation inflation that would otherwise overprice every acquisition of a prolific studio (feeding R25's Transaction Price).

**Correction (R06, authority-minor).** "Never a P11 ledger fact" is scoped explicitly to the *valuation estimate*, not to the one-time *realized proceeds* of an actual R07–R10/R17 sale, which are always a typed ledger row. Without this scoping, R06 read literally could be misapplied to block the very sale-proceeds entries R07–R10/R17 require.

Shelved/unproduced properties: unchanged, retain ownership permanently and by default valuelessly (R06).

## 5. Acquisition operating model

Model D is confirmed as the sole operating model; Model B remains excluded. One rationale correction, one added guard.

**Correction (R11, authority-minor).** R11's rationale overclaimed certainty ("a demonstrated... failure mode, not a judgment call") for a conclusion its own cited source (dossier 13) explicitly labels **INFERENCE**. Corrected: the Model-B exclusion follows from (a) the assignment's own explicit Owner statement against managing multiple independent studio operations, and (b) a well-corroborated but still-inferential comparator/code synthesis — carried forward as INFERENCE, not restated as settled fact.

**Correction (R12, exploit-moderate).** R12 defines a retained label as strictly zero-ops but was silent on two things a sibling rule (R10) and the cited GearCity precedent directly created exploits from: (1) **reputation laundering** — nothing forbade a retained label from carrying its own Standing/reputation lane (the one part of the GearCity "marque" precedent this ruleset does *not* adopt), letting a player dump every risky release's reputational cost onto a disposable shell with no consequence to the real managed studio; (2) a **hollow-shell brand flip** — R10 permits selling a label "on its own for cash," but a label with zero attached rights has no cost basis, making any price for it unprincipled by construction (this is exactly GearCity's own patched "$7B from buying and selling companies" exploit). **Smallest correction:** two clauses added directly to R12 (see Rule List) — no reputation channel of its own; no independent sale value unless bundled with at least one specific R1/R2 right (sale floor $0 otherwise).

**Correction (R13, authority-moderate + exploit-moderate).** Two related fixes. (1) R13 named only "the weekly tick loop and the save validator" as consumers of the H5 terminal state; the active-rival floor (R29) and any future AI-bid-eligibility check were not named, so a cheap remediation (a frozen zombie `RivalBusiness` row rather than a real status field) could satisfy R13's literal text while letting the floor/eligibility checks keep counting zombie rows as "operating" — defeating the floor by construction. (2) R13 under-specified H5 as a two-touchpoint patch when the corpus's own settled P15 §11/§12.3 all-owner-transaction law requires operating-state edges to commit atomically across every touched package, exactly as this ruleset already requires for the analogous P15B closure/estate correction (R26). **Smallest correction:** name all required consumers of the terminal flag, and require the same atomic participant-manifest commit (P10/P11/P12/P13/P14) already used for R26.

**Correction (R14, exploit-minor).** `successorStudioId` is a display/history pointer only and must never be read by any code path as a substitute for the R03 `ownershipEvents` log when determining current ownership of a specific right — closing a stale-pointer misread where a property individually sold to a third party before its originating studio was later absorbed could otherwise appear to belong to the absorbing studio.

R15 (immutable-ID law) and R16 (player never a target) both held against every authority and exploit challenge tried; no change.

## 6. Exact acquisition transfer bundle

**1) Acquired cash → buyer cash at par (R17).** **Correction (authority-moderate + exploit-moderate).** R17's own "net of cash" convention was never actually reconciled with §14's Studio Valuation formula, which capitalizes cash *inside* the going-concern figure before the independence-premium multiplier applies — multiplying a cash-inclusive SV by a >1x premium silently scales the target's cash by the premium instead of passing it through at par, directly contradicting §14's own "cash always at par, never capitalised" rule. The document's own worked scenarios (A vs. B) applied the convention inconsistently, reproducing in miniature OpenTTD's own patched "mixed convention" exploit. **Smallest correction:** strip target cash out of SV before the premium multiplies, add it back afterward at par (`Transaction Price = (SV excl. cash × premium) + cash at par`), compute the ledger movement and the price adjustment as **one** reconciled transaction, and floor every Transaction Price and Liquidation Reserve at **$0** (never negative — excess negative-cash burden stays the source estate's/P15's problem). Paper Scenario B's own arithmetic is corrected below (§21) to match.

**2) Debt (R18).** No debt instrument exists; "DEBT/LIABILITIES" means existing typed obligations only. **Correction (exploit-moderate).** Nothing previously required those obligations to be **subtracted at full value** from the headline price in a *healthy* (non-assumption) acquisition, letting a buyer pay full SV×premium and then separately inherit unpriced guarantee obligations under R19's "transfers intact" rule. **Smallest correction:** ongoing typed obligations are subtracted at full value from whichever valuation lane produces the headline price, for every acquisition path, healthy or distressed.

**3) Employee contracts (R19).** **Correction (authority-moderate).** The evidence base's own F5.4 correction specifies the new contract's `signingBonus` should be **0**, not a copy of the original nonzero figure — the original bonus was already paid and settled under the *old* contractId; carrying it forward as a live figure on a contractId that never paid it misstates the obligation and manufactures an unnecessary ledger exemption. **Fixed:** `signingBonus: 0` on the new row; the ledger-exemption for the `assumed` reason code is kept (still needed structurally) but no longer papers over a misrepresented amount.

**4) Ordinary termination afterward.** Unchanged, and now demonstrably safe from an "assume cheap, fire immediately" arbitrage (exploit-moderate on R19) now that obligations are netted at full value into the price under the R18 fix.

**5) Active movies (R20).** **Correction (authority-moderate).** R20 gave the buyer an unconditional continue-or-cancel choice with no accounting for the case where the single managed lot **cannot structurally satisfy** an inherited production's reservation needs (dossier 04's own F6.3 hazard: reservations naming a rival facility id fail on re-formation and may `REFUSE for capacity`). **Fixed:** a capacity-refused re-formation auto-cancels at the ordinary write-off cost rather than being left as an undefined buyer preference.

**New (R20, exploit-moderate).** An unaddressed case: an **inbound** Licence where the *target* is the grantee of a third-party rival's exclusive R3/R4 right. Because contracts otherwise "transfer intact," a plain reading let an acquirer inherit a target's exclusive claim on a *different* rival's franchise with no reference to that rival's own consent or willingness law — a backdoor around another rival's R24 refusal right. **Fixed:** an inbound Licence reverts to the grantor at closing unless its terms explicitly permit assignment, or grantor consent is a stated closing condition.

**6) Target facilities (R21).** **Correction (authority-minor + exploit-minor).** R21's own text named "land" as something that "automatically liquidates," but land purchase does not exist in accepted code at all (P09-REQ-035 LATER) — the rule's own §7 discussion already gets this right; the rule text did not. **Fixed:** scope R21 to facilities/equipment credits only; land is unpriced until a land market ships. Also added: the day rival facilities gain a real tier/footprint model, the player-parity sell/liquidate choice (§7 option 2) extends to acquired facilities of a tier the buyer lacks, rather than defaulting to forced liquidation forever — a forward-looking carve-out, not a change to current (near-moot) behavior.

**7) Acquired research (R22).** Unchanged core rule (knowledge only, no teleported installation). **Correction (authority-minor + exploit-moderate).** Added an explicit caveat that this is currently near-moot for rival targets (no tier field exists), and a note that R22 applies **uniformly** across every acquisition path including the cheapest clean bankruptcy asset-lot purchase — closing a scenario where a cheap, distressed, tech-rich target could receive Tier-III eligibility "for free" if a builder gated R22 only to the pricier healthy-acquisition path.

**8) Higher physical tier (R22).** Unchanged: knowledge-only eligibility, stated as general law for a future rival-facility system; explicitly flagged as currently a near-no-op.

## 10. Rival M&A

**Correction (R28, authority-severe + exploit-moderate → structural).** R28's literal text ("identical...law applies whether the buyer or seller is the player or a rival AI...no isPlayer...exemption...anywhere in the transaction law") contains **no carve-out** for R16's own settled exclusion of the player as an acquisition target. Read alone — especially by whoever eventually authorizes the "first-ever cross-business read" AI bid-decision function this section itself flags as needing explicit authorization — R28 could be implemented to make the player biddable, reproducing Railway Empire's single most-hated failure mode found anywhere in this research program, which OpenTTD's own code explicitly forbids in the reverse direction. **Smallest correction: append the carve-out directly into R28's own rule text**, not just the surrounding prose — see Rule List. It closes only the **acquisition-caused** vector; ordinary P15 closure/bankruptcy with no P16 transaction claiming the estate depletes the registry identically and is untouched by R29, remaining contingent on the same not-yet-authorized P15B slice as Owner Decision #1. **Fixed:** rationale rescoped; R29 alone is not represented as sufficient protection.

Everything else in this section (no player-only superpower, AI bid conditions, frequency/consolidation guards) is unchanged and held against every challenge.

## 11. Asset sales & exploit guards

**Correction (R08/R09 boundary, exploit-severe → structural).** R08's holdback cap ("at or below acquisition cost") and R09's general floor ("strictly below... absent a genuine competing bid") collided at the at-cost boundary, and neither rule stated which governs when both could apply to the *same* sale — R09's competing-bid exception, read as unqualified, could silently override R08's holdback cap and reopen the exact immediate-flip pattern the holdback exists to prevent (a rational bidder can cheaply manufacture a second "genuine" bid). **Smallest correction:** R09's competing-bid exception **never** overrides an applicable R08 holdback cap; where both could apply, the stricter (lower) ceiling governs, and the exception can raise price above cost only for assets currently **outside** any holdback window. R08's own cap is also tightened to "strictly below," matching R09, removing the at-cost collision entirely.

**Correction (R08, authority-moderate + exploit-moderate).** Two further fixes to R08: (1) dropped the overclaimed "direct transposition of the original's own eight-year Star-tenure vesting rule" framing — the original's *only* actual IP-asset-sale precedent (unproduced script sale) had **zero** vesting; the holdback is a successor anti-flip invention (fair per §2.D/K, but mislabeled as parity). (2) The 52-week cliff had no post-window guard at all: once elapsed, "full appraised value is reachable" unconditionally, letting a *distress-sourced* asset (bought near 0.5× basis) be warehoused through the clock and resold near double, risk-free, with only elapsed time as friction — a slow-motion version of GearCity's own repeatedly-patched flip exploit. **Fixed:** the **first** post-holdback resale of any asset originally acquired below its own liquidation/property basis stays subject to R09's genuine-competing-bid discipline even after the window elapses.

**Correction (R09, authority-moderate).** R09's competing-bid exception presupposed a marketplace/second-bidder mechanism that exists **nowhere** in R01–R32 for an ordinary (non-bankruptcy) sale — only R26's bankruptcy sealed-comparison has one. As written, the exception was either dead language or a silent bankruptcy-mechanism leak. **Fixed:** scoped explicitly to the R26 bankruptcy process, or to a future minimal second-bidder registration primitive for ordinary sales — flagged as a genuine new Owner decision (§20, item 11) rather than assumed.

**Correction (R10, authority-moderate + exploit-minor).** R10 was tagged P16B alone though it touches a P12-owned fact (StudioIdentity/display-credit); it also lacked an explicit cross-reference to the R03 single-holder discipline it implicitly relies on to prevent a duplicated label sale. **Fixed:** retagged P12/P16B; explicit cross-reference to R03 added; explicit tie to R12's new "no sale value without an attached right" clause.

Everything else (single holder/append-only, deterministic shown price, no guaranteed buyer, no AI-memory heuristic) is unchanged and held.

## 12. Healthy-studio acquisition

**Correction (R24, authority-moderate + exploit-minor).** R24 folded "any P15 condition fact if distressed" into a pre-offer *public* disclosure with no stated authorization for surfacing internal P15 phase state before an offer exists — contradicting the accepted visibility taxonomy (rival internal condition state is HIDDEN by default) and its own sibling rule R27, which correctly gates comparable facts behind a post-offer due-diligence event. **Fixed:** the P15-condition-derived component of Willingness State is surfaced only once the same due-diligence disclosure R27 defines has been opened; pre-offer, willingness derives from already-public inputs only (performance/Standing trend, independence-preference trait). This is stated as a dependency, not assumed as already-authorized disclosure law (new Owner decision, §20 item 13).

**Correction (R24, exploit-moderate, shared with R25).** Willingness State and the Studio Valuation pricing term both read the same short "recent performance" window, letting a single manufactured short-term dip (e.g., player-triggered genre/release-window saturation, a lever this ruleset's own §17 confirms exists and is player-controllable) move both the eligibility gate and the price at once — buy a target's durable assets at a price set purely by an engineered trough that rolls out of the window the moment the deal closes. **Fixed:** willingness-state transitions require a minimum run of consecutive below/above-threshold periods (not a single-period read), **and** R25's SV pricing term is computed on a longer, independently-smoothed window with a floor tied to the studio's non-cyclical asset base — so one manufactured event cannot move both numbers together.

**Correction (R27, exploit-moderate).** The due-diligence disclosure event R27 introduces as the sanctioned alternative to reading hidden state had no cost, exclusivity, or cooldown of its own, and R24/R30's cooldowns attach only to a *rejected offer* — leaving a free, unlimited scouting loop (open diligence, read the snapshot, close, repeat on every rival every period) that defeats the exact visibility doctrine R27 exists to protect. **Fixed:** opening a due-diligence event itself counts as a formal approach for cooldown purposes (the same per-(buyer,target) cooldown a rejected offer triggers) and carries a modest one-time cash cost.

Willingness-state label set (`NotForSale|Reluctant|Open|Willing`), the independence-premium naming correction, and the refusal-with-reason/cooldown model are all unchanged and held.

## 13. Bankruptcy auction/acquisition

**Correction (R26, authority-moderate → structural, restated).** The rule as excerpted described a fully operative disposition system with no inline flag that it is entirely contingent on an Owner authorization (the P15B pre-settlement estate window) that does not currently exist under approved P15 law, which settles every category exhaustively with **no** transferable estate. **Fixed:** the contingency is now stated inline, in the rule's own statement, not only in surrounding prose or metadata.

**Correction (R26, exploit-moderate).** Two breaks in the three-path model as worded: (1) unsold lots "persist for later purchase" at the same reserve while the reserve can independently "fall... if no bidders" — combined, a rational bidder has zero incentive to ever bid in the live window (waiting never costs and may pay off), defeating the auction's purpose entirely; (2) "ties broken by earliest bid" structurally favors whichever party reacts fastest — the player, against tick-paced AI — the same asymmetry §2.L warns against. **Fixed:** the post-window catalogue price is locked at the reserve set at window close (it may fall once more from continued no-bidder pressure, but never drifts down indefinitely while unsold, so waiting stops being strictly dominant); ties are broken by highest private valuation (or a fixed random tiebreak), never by raw reaction speed.

Everything else in this section (default clean-lots path, optional cure-cost assumption, whole-entity reorganization reserved case, no live multi-round bidding) is unchanged and held.

## 14. Book Net Worth vs Enterprise Valuation vs Transaction/Auction Price

**Correction (R23, authority-moderate).** Two evidence-conflicts fixed. (1) `package_owner` and the "computable from P11 rows alone with no new authority" framing misstated P11's actual authority — approved P11 law explicitly forbids inventing or displaying any net-worth/balance-sheet concept; BNW is entirely new **P16** read-model authority over raw P11/P09 fields, not a P11 fact. **Fixed:** package_owner corrected to plain P16 (a new derived read model; P11 itself never computes or displays "net worth"). (2) The "brand informational only" clause cited dossier 08's Amazon/MGM analysis as support, but that dossier actually recommends the *opposite* — a single, quantified, premium-bearing brand line. **Fixed:** the "informational only, never priced separately" clause is now scoped explicitly to the four-number BNW/SV/Transaction/Auction ladder for a **whole-company** deal; it does not override a standalone brand-only sale under R10/R07, which keeps its own independent Estimated Value.

**Correction (R23, exploit-moderate).** The going-concern trailing-performance term ("capitalises trailing operating performance ... plus ... Story Property/library value") risked double-counting: capitalizing trailing performance already prices the firm's ongoing ability to exploit its existing catalog (future sequels/prestige), so adding an *explicit* library-value addend on top of an unbounded, perpetuity-style earnings multiple prices the same optionality twice — exactly the "tangled web" Damodaran's own cited finding warns against. **Fixed:** the trailing-performance term is computed on a bounded, non-perpetuity basis (a short explicit multiple on recent realized operating cash flow, no assumed continuing-growth/terminal-value component).

**Correction (R17, restated here — see §6.Q1).** Cash-netting arithmetic fixed and floored at $0; Paper Scenario B's numbers corrected below (§21) to match.

The four-number ladder itself (BNW / SV=`max(going-concern, asset basis)` / Transaction Price / Auction Price), the "healthy from enterprise value + premium, distressed from liquidation/bids" answer to §2.N, and the one-lane-per-asset discipline are otherwise unchanged and held.

## 15. Real-world lessons

Unchanged from `merged-ruleset.md` §15 — no refutation in this pass targeted this section's ten cases; they remain load-bearing evidence for §5, §9, §12, §13, §14, and now additionally for the R08/R12/R20 corrections above.

Ten cases carry direct, load-bearing design weight:

- **Disney/Pixar (2006)** — the creative studio and the film-ownership rights can sit with two different parties; rights ownership and operating-studio identity are genuinely separable, exactly as §3 assumes.
- **Disney/Marvel (2009)** and **Disney/Lucasfilm (2012)** — buying a company does not unwind licences its properties already carry (Paramount's Marvel distribution deal survived intact), and a franchise's future creative direction does not transfer even when the property does (Lucas's own sequel outlines were discarded). R1 transferring never implies the buyer inherits every downstream commitment automatically — encumbrances travel *with* the property. This is also the direct precedent for R20's new inbound-Licence-reverts-to-grantor correction: an encumbrance running *the other way* (a target holding a licence *from* a third party) does not travel to the buyer either, absent assignment terms or consent.
- **Disney/21st Century Fox (2019)** — the real-world Model C: operations absorbed, brand renamed/kept as a label ("20th Century Studios"), the physical lot stayed with the seller, and the inherited slate produced a real write-down ($170M). The closest real precedent to the exact model the Owner selected.
- **Amazon/MGM (2021)** — the cleanest real proof that library value and brand/strategic value are different numbers even inside one purchase-price allocation, and that whole-company purchases transfer assumed cash/debt at par (the $2.5B assumed and immediately repaid). Directly supports §14's discipline and the corrected §6.Q1/R17 par-transfer-then-add-back convention.
- **DreamWorks/Soros (2006)** — a library sold *separately* from the operating studio, with distribution kept as a term licence and a buy-back clause at a different price years later ($900M sold, ~$400M repurchased). Direct precedent for §11's holdback/re-buy pricing discipline (now extended past the holdback window for distress-sourced assets, R08) and §3's encumbered-sale model (R04c).
- **Spider-Man (Sony/Marvel)** — the cleanest real rights model found: property stays with the owner, an activity-conditioned exclusive licence goes to another party, and reversion is a readable clock (release a film at least every 5.75 years or lose it). Direct real-world ancestor of R3's `useItOrLoseIt` field, and of R31's sequential-licensing-is-not-co-production clarification.
- **The Weinstein Company §363 sale (2018)** — demonstrates every alternative in §2.M in one real transaction: a stalking-horse floor that moved *down* (no competing bids), assets transferred free and clear, a capped buyer-chosen list of assumed contracts, and an unpaid producer's back-end claim left stranded with the estate because the contract was non-executory. The primary real-world template for §13's hybrid, and for R26's now-corrected "waiting is never strictly dominant" fix (TWC's own price cut happened once, at closing, not as a standing invitation to wait indefinitely).
- **Carolco (1995–96)** — a rival bidder (Canal+) beat the stalking horse ($58M vs $47.5M), and continuation rights were auctioned as a *separate* lot from the library. Direct precedent for §13's per-lot design and for R3's separate tradability.
- **RKO Pictures** — the exact real-world analogue of the Owner's three worked history examples: library, real estate, name, and remake rights ended up as four separately owned things while authorship credit stayed with RKO throughout. Direct precedent for §9's identity model and for R14's successorStudioId-is-display-only correction.
- **Control premiums cluster 20–40%** in the real world, rise with rival bidders, and boards refuse regardless of price (Disney/Comcast 2004) or accept a lower bid for certainty (Fox chose Disney over a higher Comcast cash offer, on regulatory-risk grounds). Direct precedent for §12's refusal-with-reason and premium-band model, now corrected (R25) to draw its pricing window independently from the willingness-state window.

The universal negative lesson across every case: **facilities never teleport.** Every acquisition researched left the target's physical lot with someone other than the buyer, or sold it as a wholly separate transaction — reinforcing §7's automatic-liquidation default (now correctly scoped away from land, R21) as the observed real pattern, not a code convenience.

## 16. Comparator lessons

Unchanged from `merged-ruleset.md` §16 — no refutation in this pass targeted this section directly; its findings are the evidentiary basis for several of the corrections above.

Across nineteen-plus titles researched, the pattern is consistent enough to be treated as near-law:

- **Autonomous subsidiaries are the one shipped anti-pattern everyone converges on**, for the same reason in three unrelated engines: MGT2's are "a fiction" run by a timer with no real employees; Capitalism Lab's AI-CEO subsidiaries override the player's own decisions and "do literally nothing"; Software Inc.'s are "a source of never ending cash." This is the strongest evidence *against* Model B and *for* Model D (§5, R11 — restated as INFERENCE, not certainty, per the R11 correction).
- **A shipped willingness model is a small, typed, visible thing, not a formula.** GearCity's health-driven shareholder vote, TEW's stance-plus-relationship, FM's Desperate/Keen/Curious, Big Ambitions' shown-valuation-with-refusal — none hide the driver behind a black box. §12 follows this exactly, now with independently-windowed inputs so the visible driver cannot be silently manufactured (R24/R25).
- **Partial ownership stakes are a uniformly failed idea.** OpenTTD removed share trading entirely in 2024, calling it "generate infinite money ... ABSOLUTELY NOTHING" for player decisions. Blockbuster Inc. disabled its own stake dividends because the game became too easy. GearCity's own flip exploits required repeated patches — now cited twice more precisely in this ruleset, once for R08's post-holdback flip guard and once for R12's no-bare-brand-value guard. Startup Company's unrestricted share-buying produced a documented complete monopoly. No comparator's partial-stake system survived scrutiny. This ruleset includes none (§17, R31).
- **A transferable asset that gates exclusive access to a shared audience/market channel snowballs without bound.** Hollywood Animal's purchasable cinemas — "buying cinemas is basically the meta" — destroyed rivals' ability to compete, and the developer's only fix was a scripted decree stripping theaters from everyone. This is directly checked against Project: Studio's own market design in §17 and found **not to apply today** — a genuine, independently-confirmed non-collision, not a gap this ruleset had to close.
- **Model C's brand-as-label is a real, playable, shipped pattern**, not a hopeful invention: GearCity's "marque" is exactly this — a brand that "does not operate independently from the company" yet keeps its own reputation lane and a full disposal menu (spin-off/sell/discontinue/restore). One negative comparator confirms the boundary by counterexample: TEW's parent/child companies keep operating their own roster and shows, which is functionally Model B, not C/D, and is exactly what a "retained label" must never become. The assignment's TEW "tape-library" premise itself does not exist in any TEW title checked and should be dropped (§19). **Correction (R12):** GearCity's "own reputation lane" is the one element of this precedent this ruleset explicitly does *not* adopt, closing a reputation-laundering exploit a retained label would otherwise enable.
- **No comparator runs a live, multi-round bidding war for distressed assets.** Every one uses a fixed clearing price, a creditor-priority sale, a paused evaluation window, or a sealed one-shot comparison. §13's design follows this, now with a tiebreak and post-window price rule (R26) that removes the one place a patient/fast-reacting bidder could otherwise dominate for free.
- **Inherited operations are a burden, not a reward.** Offworld Trading Company's designer explicitly documents that all-or-nothing buyouts left players managing buildings across the map "they didn't have time to manage" — confirming the Owner's single-lot preference from the player-experience side, not just the engineering side.

## Paper scenarios A–F (updated for changed rules)

All figures are PAPER HYPOTHESES illustrating the rules above, not tuned constants.

### A — Bankrupt small studio (weak cash, modest properties, several employees, no valuable technology)

Assume: cash −$50,000; abstract tangible capacity original cost $2,000,000 (recoverable credit at 0.5× = $1,000,000); 3 small Story Properties appraised at $50,000 each ($150,000 total); 6 employees with combined remaining guarantees of $900,000; no technology of note.

- **Liquidation Value (asset basis):** $1,000,000 (tangible) + $150,000 (properties) − $50,000 (overdraft) = **$1,100,000** (floored at $0 by R17 if the overdraft were ever larger than the tangible+properties sum — not the case here).
- **Buy Individual Lots, clean:** a buyer pays roughly $1,100,000 in total across the separate lots, assumes zero obligations; the six employees are released to the open talent pool by the estate. **R09/R08 correction applied:** if this buyer later resells any of these lots, the first resale (this studio was distress-sourced) stays subject to R09's genuine-competing-bid discipline even once R08's 52-week holdback elapses — closing the flip loophole this scenario would otherwise open.
- **Buy Individual Lots + Assume Named Contracts:** a buyer pays a lower cash amount up front (say $250,000) but assumes the $900,000 of employment guarantees at cure cost — under **R18's correction**, this $900,000 must be netted at full value into the disclosed headline price the buyer sees, so the "$250,000 headline" is shown alongside the full $1,150,000 all-in cost, not as a hidden surprise. Terminating the inherited roster immediately afterward (R19) costs 50% of $900,000 = $450,000 — total $700,000, still cheaper than clean, but no longer a hidden windfall since the obligation was priced in up front rather than omitted.
- **Buy the Whole Studio (going-concern):** only makes sense if a bidder specifically wants the StudioId's historical continuity for a label; otherwise the two asset-lot paths above dominate. Per **R12's correction**, that label carries no reputation lane of its own and no independent resale value without an attached right.

**What this demonstrates:** the three-path model from §13 gives a legible trade-off — cheap-and-clean vs. cheap-plus-obligations vs. pay-in-full-and-keep-the-name — without any bidding mechanism, and the R18/R19 corrections ensure the "cheap-plus-obligations" path's true cost is always visible rather than assembled from two separately-priced, easy-to-miss steps.

### B — Valuable distressed studio (heavy debt, valuable library, excellent research, several active productions)

Assume: cash −$5,000,000; recoverable tangible $1,500,000; locked scheduled receipts $500,000; contract guarantees $2,000,000; library appraised strategic value $8,000,000 (5 properties, 40 films, none co-holding both R1 and R2 on the same title — so R06's co-holding fix does not change this figure); buyer-relative avoided-research value from the target's completed Technology III $2,000,000; two active productions carrying $3,000,000 of sunk, recoverable-in-place committed cost.

- **Book Net Worth** = −5,000,000 + 1,500,000 + 500,000 − 2,000,000 = **−$5,000,000**.
- **Studio Valuation (asset basis, since going-concern is near zero for a distressed target)** = $2,000,000 (tangible+receipts) + $8,000,000 (library) + $2,000,000 (buyer-relative tech) ≈ **$12,000,000** buyer-specific ceiling, though a generic (non-tech-seeking) bidder's SV is closer to **$10,000,000**.
- **Auction/Liquidation reserve (R17-corrected statement)** = tangible + receipts **only**, with the target's negative cash already netted into BNW rather than double-subtracted here = **$2,000,000**, rising with competing bids toward, but rationally never exceeding, the second-highest bidder's private value — clearing, say, at **$6,500,000**. Per the **R09/R08 correction**, whatever this clears at, the buyer's first resale of any of these distressed-sourced lots stays gated by R09's competing-bid discipline even past the 52-week holdback.

**What this demonstrates:** BNW (−$5,000,000), Studio Valuation (~$10–12,000,000), and Auction Price (~$6,500,000) are three genuinely different numbers computed from the same facts, exactly per §14's discipline — none is a garbled average of the others, and a BNW-only reading ("worthless, avoid") and an SV-only reading ("valuable, pursue") of the *same studio* point in opposite directions. The R17 correction changes *how* the reserve is derived (cash excluded from this lane by definition, not subtracted twice) without changing this scenario's number, since BNW already carries the cash effect once.

### C — Healthy rival (profitable, strong brand, valuable properties, does not want to sell)

Assume: Studio Valuation $9,700,000 (illustratively cash-neutral); public willingness state `Reluctant`; premium band 1.4×–1.8× ⇒ asking range **$13,580,000–$17,460,000**, computed under the **R17-corrected formula** as `(SV excluding target cash × premium) + target cash at par` — unchanged in this illustration only because the target's cash is assumed neutral; a target carrying meaningfully negative cash would previously have had that cash incorrectly scaled by the 1.4–1.8× premium, and now is not. A buyer's own rational parts-value ceiling for absorbing this target as a one-lot addition (its recoverable tangible plus its properties at buyer-relative, non-duplicated worth) computes to roughly **$6,864,000**.

**What this demonstrates:** the buyer's rational ceiling ($6.86M) sits well below even the low end of the seller's asking range ($13.58M). This is not a bug; it is §17's Rule 3 working exactly as intended — a strong, well-run target is *structurally* hard to acquire at a price that makes sense for the buyer, without any artificial cap. The independence-premium naming makes clear this gap is the cost of the seller's reluctance, not the buyer's synergy. **Correction applied (R24/R25):** this target's `Reluctant` label and its $9.7M SV must now be read from independently-smoothed windows — a player cannot manufacture a single short-term dip (e.g., a genre-saturation play against this rival) and expect both the willingness label and the $9.7M figure to move together from that one event.

### D — Technology target (player buys mainly for research it lacks)

Assume: buyer lacks Technology III; target has it, completed; avoided-research value estimated at $2,000,000; whole-studio purchase price $3,000,000; the physical Tier-III facility body still costs $800,000 capex to build after closing, taking N weeks. Per the **R22 correction**, this knowledge-transfer rule now applies identically whether this is a healthy $3,000,000 purchase (as here) or the cheapest clean bankruptcy asset-lot path — a builder may not skip technology-grant law just because the deal is priced as a bankruptcy lot.

- **Acquisition path total effective cost:** $3,000,000 (purchase) + $800,000 (mandatory build) = **$3,800,000**, available as soon as the build finishes.
- **Organic path total effective cost:** ~$2,000,000 (hypothetical R&D) + $800,000 (build) = **$2,800,000**, but only after however many weeks the research itself would have taken.

**What this demonstrates:** the acquisition path is not "free capability" — it costs *more* in cash than researching it yourself, and it still requires the same physical build afterward. What it buys is **time**, not magic — the exact reading of "knowledge transfers, installations do not" the Owner's §2.F direction requires, verified with arithmetic rather than asserted.

### E — Serial acquirer (three studios in ten years)

Walking through three sequential deals against a starting field of nine rivals: after deal #1, active rivals fall from 9 to 8; after deal #2, to 7; each deal also drains the buyer's own affordability buffer (§17 Rule 2) and adds one more retained label or absorbed roster to triage. By deal #3 (rivals at 6, still comfortably above the floor of 3), the acquirer carries three sets of inherited obligations — each now **fully netted into the price paid at closing** under the R18 correction, so the acquirer cannot understate its own cumulative commitments across three deals the way an unpriced-obligations reading would have allowed — three holdback timers on inherited assets (each now extended past the window for its first resale if distress-sourced, per R08/R09), and a shrinking pool of remaining targets whose premiums have not fallen — nothing in the rules makes later deals *cheaper*. If inherited contracts transfer intact with no bound (§20 decision #2), the talent-pool concentration guard (§17 Rule 5) caps how much of the fixed 60-person pool any single acquirer can actually hold onto post-integration; **per the R30 correction, this cap bounds aggregate headcount only** — it does not stop the acquirer from cherry-picking the single most valuable inherited Star across all three deals while dumping the rest, a distinct concentration risk this scenario surfaces and which remains open pending Owner Decision #2 — and **per the same correction, any contracts left untouched at each deal's integration-window close are now automatically terminated**, not left to linger. The concrete exploit this scenario surfaces without a holdback rule: absent §11's holdback, the buyer could immediately re-sell a freshly acquired library at full appraised value for instant profit; **with** the rule (and its R08/R09 post-window extension for distress-sourced assets), that value is only reachable after the holdback period **and**, for the cheaply-bought lots among these three deals, only via a genuinely competing bid even after that. A fourth or fifth acquisition being *harder in principle*, not just *scarcer in targets*, would be a new "serial-acquirer wariness" ask-price escalation — explicitly **not recommended initially**, since it would add a second hidden multiplier exactly where §12 tries to keep one visible number.

### F — Rival acquires rival (symmetry and history preservation)

Rival A (willingness state: `Open`, distressed) is bought by Rival B under the identical §12/§13 rules a player purchase would use — same affordability check, same premium band, same active-rival-floor predicate, and now the same **R28-corrected** symmetric law that, read in its own text, explicitly excludes only the player's studio from ever being a target, never a rival-to-rival deal like this one. Mechanically this is *cheaper* to build than a player-directed purchase, because both sides already share identical `Production`/`ScriptDevelopment` array shapes and rival facilities never bind to a placement ledger. Rival A's `StudioId` remains in the fixed registry forever; its films still credit Rival A as creator; a `CorporateEvent{kind:'acquired', successorStudioId: B, brandRetained: true|false}` marks the transaction publicly, exactly as §9 specifies for a player-directed deal — and per the **R14 correction**, any code path checking who currently holds a specific right Rival A once owned must still consult the R03 `ownershipEvents` ledger, never infer current ownership from this `successorStudioId` pointer alone. If Rival B is itself later absorbed by Rival C, the chain (A→B→C) stays a dated, walkable sequence of successor pointers — never a rewrite of A's or B's original identity, and never a shortcut for "who owns what" queries.

**What this demonstrates:** "symmetric transaction law" is not an aspiration bolted on afterward; it falls out of using the same rules and the same append-only history model regardless of which side of the transaction is a player — and, after the R28 correction, that symmetry is now legible from R28's own text rather than depending on a reader also finding R16.
