## 2. Refuted or weak claims

### 2.1 REFUTED — §8 / summary item 20: "no rival studio, shared saturation, or ranking anywhere in src/, bridge/, or ui/src/engine/ (grep ... returned nothing)"

The accepted P12 R05 snapshot 592e926 **is** the "Living Hollywood" candidate (see `authority/P12-R05-OWNER-ACCEPTANCE-RECEIPT.md` line 19: `P12A-Living-Hollywood-Candidate-592e926-…`). What it contains, at exact locators:

- `src/core/calendar.ts:3` — `RIVAL_ARRIVAL_WEEKS = [0, 0, 0, 0, 520, 988, 1560, 1872, 2548]` under `campaign-calendar-1920-52/v1` (52 weeks/year): **nine rivals — four present at 1920, five scheduled for 1930, 1939, 1950, 1956, 1969**, an evident transcription of Prima's window midpoints (1928–32, 1937–41, 1948–52, 1954–58, 1967–71).
- `src/core/hollywoodStartingData.ts:8–41` — `HOLLYWOOD_STARTING_MANIFEST` with nine fictional studios (Bellwether Pictures, Rose Lantern Films, Night Orchard Productions, Silver Current Pictures, Marigold Motion Pictures, Blackthorn Screenworks, Trailhead Pictures, Copper Kite Films, Bright Meridian Studios), each with capital, genre anchors, marketing ratio, reserve weeks, and (for the four founders) authored back-catalogue films and starting Standing. Header comment: "Fictional scenario authoring, not recovered original-game economics."
- `src/core/hollywoodTypes.ts` — `StudioIdentity` (role `'player' | 'rival'`, `eligibleWeek`, `enteredWeek`), `RivalBusiness` (account, standing, operations, productions, runs, policy), `RivalAccount`/`RivalFinancePeriod` (cash ledger by money kind), `IndustryEmployment` (talent contracts across studios, reasons `entry|renewal|replacement|expiry|termination|player-contract`), `IndustryFilm` (authored + live), `HollywoodChartSnapshot { week, rows: {studioId, standing, output}[] }`, `HollywoodState.chart` / `previousChart`.
- `src/core/hollywood.ts:139–190` — `enterRival(state, studioId, origin)`; `src/core/tick.ts:1038–1043` — scheduled entry each tick when `eligibleWeek <= tick`.
- `src/core/hollywoodTick.ts:306–312` — a chart snapshot is recomputed **every 13 weeks** (`week%13===0`), retaining the prior snapshot.
- `bridge/industry.ts:19–24, 66–83` and `bridge/schema/industry-schema.ts:3–7` — public Industry page with four **comparison lanes** (Audience Awareness, Industry Prestige, Commercial Confidence, Released Films), each carrying a per-studio `rank`, `priorRank` and movement label ("Up N" / "Down N" / "New to this comparison"). `ui/src/engine/adapter.ts` consumes it.

What the snapshot does **not** contain (these parts of §8 are right): `computeBoxOffice` still multiplies by `competitionFactor = 1.0` (`reception.ts:679`, comment at 596); `MarketState.competingSlate` is initialised empty (`worldgen.ts:645`) and nothing populates it; there is no cross-studio genre-saturation term (grep for genre fatigue/saturation/popularity in `src/core` returns nothing); no composite "Power Ranking" or rank badge; no rival closure/dormancy/bankruptcy code (`grep -i "dorman|closure|bankrupt|insolv"` over `hollywood*.ts` is empty).

**Corrected statement:** "Accepted code 592e926 implements a fictional nine-studio rival ecosystem (P12A Living Hollywood: authored identities, scheduled arrivals mirroring Prima's windows, rival finances, cross-studio employment, industry films, and a quarterly per-lane comparison chart with rank movement exposed via `bridge/industry.ts`), but rival releases do not touch the player's box office (`competitionFactor ≡ 1.0`, `competingSlate` empty), there is no shared genre saturation, no composite studio rank, and no rival closure. Original-game saturation/head-to-head competition is un-implemented; rival studios and ranking are not." (Sources: files/lines above.)

Why it matters: the task brief warned that the P15 package's code descriptions were written against 7811377 ("rival studios/projects: absent at accepted base; designed by P12", P15-PACKAGE.md §9) and are not current truth. The report repeated that stale statement as a fresh grep result. Any P15 planning that relies on the report's §8 would wrongly treat rival studios and ranking as greenfield.
