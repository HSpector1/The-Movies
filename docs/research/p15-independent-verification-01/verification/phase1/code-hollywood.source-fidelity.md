## Refuted or weak citations

1. **`CODEX-RIVAL-STUDIOS-HOLLYWOOD-ECOSYSTEM-PACKAGE-12.md:475` cited for the rule "Use new versioned roots".** Line 475 says "Do not widen frozen recursive leaves in place…" (and lists the frozen leaves); the phrase "new versioned roots" is at **`:927`** ("Record the relationships the later implementation must be able to add through new versioned roots."). The substance is right; the line is wrong. **Weak (mis-cited line); corrected citation: `PACKAGE-12.md:475` for the no-widening rule, `:927` for the versioned-roots rule.**

2. **Summary-only figure "~38,500/week idle".** Reproducible as `OVERHEAD_BASE` 15,000 + facility opex 23,500 (`tuning.ts:419, 686, 699, 710, 731`; `hollywood.ts:88-95`), but only under a **zero-employee** assumption that the summary does not state, and the figure appears nowhere in the report body. With the six 208-week entry contracts still running, weekly burn is payroll + 9,000 per-employee overhead higher. **Weak (unstated assumption, summary/body mismatch); corrected statement: "fixed weekly burn with no employees is 38,500 (15,000 base overhead + 23,500 facility opex); payroll and 1,500/employee overhead add to that while contracts run."**

3. **`hollywoodPolicy.ts:60` paraphrase "expected operating margin beats holding".** The gate is `score<=holdOperatingMargin → continue`, where `score = expectedOperatingMargin − |marketing/negative − marketingRatio| × HOLLYWOOD_POLICY_PREFERENCE_COST` (`:59`). So it is the preference-adjusted score, not the raw margin, that must beat holding. **Minor overstatement; no consequence for the P15 conclusions.**

4. **`actions.ts:2694-2727` for `releaseTalent`.** The function spans `:2694-2725`; `:2727` is the next section's comment. **Trivial.**

5. **Prima "PDF p. 52".** Correct as a PDF page index, but the printed folio on that page is **51**. Anyone cross-referencing the printed guide or the EPUB will look for p. 51. **Clarification, not an error.**

None of these change any conclusion in the report.
