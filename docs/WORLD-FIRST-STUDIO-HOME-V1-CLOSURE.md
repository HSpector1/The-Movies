A deep management screen unmounts `StudioLotScreen` and destroys its Phaser view. Returning mounts
one replacement Lot against the same current authoritative `GameState`. “Same Lot” in this closure
means the same authoritative studio, save, URL, stable stage assignment where applicable, selected
building, and deterministic return focus.

place, Scenery, Annex presentation context, presentation-only motion, or the same Phaser instance
or object identity across a deep route. None of that state is serialized or fabricated. Persistent
