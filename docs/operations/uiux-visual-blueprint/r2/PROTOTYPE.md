# Open the R2 prototype

Extract the complete R2 ZIP and open **index.html** locally. Keep the bundled CSS, JavaScript and SVG beside it. There are no packages, servers, accounts, network requests or game dependencies. GitHub displays HTML source; use the ZIP to click through.

Everything is **PROPOSED DESIGN / MOCK DATA — NOT IMPLEMENTED**. State is fictional, in memory and resettable. No real bridge, filesystem, campaign library, preference store, economy or clock is accessed. The schematic lot translation illustrates locating; it is not native camera behavior. All portraits/icons/buildings are original code-authored illustrations.

1. **Find and track the studio.** Use the left People group selector (Talent/Writing/Crew) or search a name, role or ID. Search “Mara” to distinguish director P-004 from craft lead P-022. Hover/focus previews current work; click locates and pins the exact person. The right rail continues to show writing, casting, shooting and Post/release. “Needs me” narrows to actionable fixtures; “Waiting” isolates normal waiting. Library results remain a separate group. Scroll each list independently.
2. **Follow a picture.** Click The Glass Harbor on the right. Its local card shows current work, the set/people link and scheduling response strip. Open detailed production, scroll, click Mara in the left rail, then Back to the same production and offset. Choose success or refusal in the response fixture and stage scheduling. After the Rain demonstrates a normal no-remedy wait and the exact Post inspector.
3. **Cast from the building.** Select The Long Way Home, then its Casting building. Director/Lead/Company work areas open real prototype views. Lead opens comparison; inspect unavailable Leon, Back, review Celia, and return her to the retained draft. Review the commitment, then stage the simulated response. Nothing signs or creates a real production.
4. **Preserve progress.** Menu → Load selected → Save As → name → consequence review. Select unresolved, submit, close the view and return to Lot. Its status remains in Menu without reopening itself. Reopen, retry the same conceptual operation, receive the simulated receipt and explicitly review the original leave task before continuing.
5. **Build locally.** Build in the lower-left corner → Soundstage → valid/invalid footprint fixture → Cancel or review the cost. A staged receipt illustrates construction, not instantaneous operational capacity. Laboratory is an entry-style example only.

Tab/Shift-Tab, Enter in a campaign name, Escape/Back, More details and wheel scrolling operate in the browser. Right-click on a rail card expands local information without committing. Other visible controls either navigate or open an explicitly labeled static example. The original game’s hold-and-drag hiring/assignment gesture is not implemented here; STUDIO’s legal commands and reviews remain separate.

The View selector opens all eight families for inspection. Examples: `?screen=home`, `?screen=production&state=waiting`, `?screen=building&state=casting`, `?screen=casting&state=compare`, `?screen=building&state=catalogue`, `?screen=campaigns&state=name&text=200`. Add `&annotated` for the 300px annotation rail. Reset Demo clears all staged state.

The three original linked journeys remain; the new employee/studio-tracking path addresses the Owner’s correction. Large-text previews demonstrate prototype content reachability, not native controller, persistence, financial correctness or comprehensive accessibility acceptance. [Review record](REVIEW.md) records checks and limits.
