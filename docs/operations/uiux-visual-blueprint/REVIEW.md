## Remaining prototype limits

The prototype covers navigation and consequence presentation. It does not model time, quotes, queue admission, finances, storage, construction legality, camera motion or any authoritative law. Static controls explain their coverage. Retry is the same conceptual request in memory, not a demonstrated bridge command ID or durable operation. Fixture cash is an illustrative starting balance; a simulated commitment does not run an economy or mutate that balance. Reset clears the staged state.

The 200% setting scales workspace/commitment content; compact HUD/navigation chrome retains its reference type. Full chrome scaling remains a presentation follow-on requirement. Long lists are a finite 30-record example, not a performance benchmark. Browser focus/pointer behavior does not establish Unity hitboxes, controller behavior, Retina rendering or native safety. No user/newcomer task-success study occurred; independent design inspection is not evidence that an uncoached player has accepted the target.
