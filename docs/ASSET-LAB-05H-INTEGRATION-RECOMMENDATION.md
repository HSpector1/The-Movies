## Recommendation

## Provenance note for integration
The 05H hero incorporates CC0-derived geometry (public domain). This is the first non-original
asset in the Asset Lab pipeline; the `public/assets/studio/` "100% original" convention no longer
holds for 05H. License evidence lives in `licenses/asset-lab-05h/`; every 05H asset carries a
`studio_base` custom property naming the CC0 source. If the owner prefers to keep production
assets 100% original, Path B (original topology-first) remains the alternative — but Path A is
what was authorized and proven here.
