## Closure ruling

World-First Named Person Work & Career Inspector V1 passes its bounded Keep gate and is closed.

The Hollywood Studio Lot now makes an exact named Director or Lead actor understandable where the
person is observed. The in-world inspector joins only unique public snapshot authority, states the
person's role on one exact picture, explains the picture's current operating truth without
inventing personal location, and offers the existing canonical Talent Profile only when the full
identity and assignment handoff is exact.

```text
SEE A NAMED PERSON IN THE LIVE STUDIO
→ SELECT THAT EXACT PERSON PHYSICALLY OR SEMANTICALLY
→ UNDERSTAND THEIR EXACT PICTURE WORK AND PUBLIC CAREER CONTEXT
→ OPEN THE CANONICAL TALENT PROFILE IF NEEDED

→ RETURN TO THE SAME MOUNTED LIVE WORLD AND PERSON
```

The Lot remains the primary game surface. The Talent Profile supplies supporting depth without
becoming a new screen, route, home, or second read model.

## Authority and fail-closed ruling

`lotPersonWorkContext` reads only `StudioLotSnapshot`. It accepts one person-to-picture join only
when person identity, role, production ID/title, operation membership, participant name, mode, and
provenance agree uniquely. Managed snapshots may expose the picture's production facilities;
legacy snapshots explicitly withhold workplace authority.

Duplicate identities or operations, cross-production reuse, dual Director/Lead membership,
missing participant projection, stale identity, contradictory provenance, and unsupported
authority return unavailable. A separate whole-studio gate counts every active production role
and screenplay assignment before assignment copy, career summary, or profile handoff is allowed.
There is no first/last-match or array-order fallback.

The career summary and detailed drawer continue to use existing public/perceived Talent Profile
selectors. A person's primary career discipline is not required to equal their temporary role on
the picture, so legal cross-discipline work remains supported without weakening identity checks.

## Same-world modal continuity ruling

The Talent Profile opens as an App-owned overlay while `screen.kind` remains Lot. The same
`StudioLotScreen`, `StudioLotView`, Phaser game, canvas DOM node, selected person, production
context, camera framing, URL, and authoritative `GameState` remain mounted and unchanged.

While the drawer is open, presentation-only input suspension blocks Phaser pointer, mouse, touch,
wheel, keyboard, held-key, and drag state without destroying the renderer or stopping ambience.
The boundary composes with delayed lazy readiness and document visibility, and is reapplied if an
independent view recreation occurs. Profile open/close itself requests no recreation.

Close button, Escape, and scrim activation restore the exact opener. If the person or the exact
handoff authority disappears while open, the raw open ID is cleared once, the profile cannot
transfer or auto-reopen, and focus returns to the named-people group or Lot heading.
