## Read this first

P09A is not a new construction engine. It is a **Founding Flip, bridge, and Unity presentation integration** over a strong existing engine/browser contract.

The non-negotiable boundary is:

> TypeScript quotes and commits. Unity previews and submits. A preview may be beautiful; it is never law.

The highest-risk mistake is editing `INITIAL_PROPERTY` or treating the legacy `startConstruction` intent as a generic facility action. The highest-value reuse is `src/core/placement.ts` plus the browser’s world-first build behavior.

## A1. The original Build loop — the historical heart

- **Game:** *The Movies* (2005)
- **Exact source:** [official manual PDF](https://cdn.steamstatic.com/steam/apps/7900/manuals/manual_english.pdf?t=1447351040), printed p. 10, **“Hiring Builders”** and **“Building Up Your Studio”**; PDF p. 5. Continue through printed pp. 11–12 for the first production chain.

### B3.1 Required P09A protocol increment

P09A is a breaking closed-schema addition. Increment the current protocol/projection version together (current is 4; next is **5**) and regenerate schema artifacts and C# DTOs through `scripts/generate-bridge-contract.ts`. Never hand-edit generated C#.

Add one read-only `POST /construction/quote` route, correlated but mutation-free. It is deliberately outside the mutation journal: request validation and response schema are versioned, but a quote cannot consume a command ID or create a runtime-checkpoint entry.

```text
quoteFacilityPlacement {
  protocolVersion, schemaId, sessionId, requestId,
  expectedStateRevision,
  payload: { blueprintId, origin:{gx,gy}, clientDraftRevision }
}
```

The response echoes correlation/revision/request and publishes the complete current `PlacementQuote`: `ok`, exact origin/parcel/cells/cellLegality, cost, weekly operating cost, build weeks/completion week, capability/capacity delta, ordered `rejections`/`primary`, unmet requirements, instance count, and maximum. It calls `queryPlacement()` only and performs **no** action, journal mutation, save write, RNG use, charge, ID allocation, or state-revision increment. A client renders it only while session, request, draft revision, blueprint, and origin still match the live draft.

Add one parameterized mutation command to the existing command route:

```text
placeFacility {
  protocolVersion, schemaId, sessionId, commandId,
  expectedStateRevision,
  payload: { blueprintId, origin:{gx,gy} }
}
```

The server maps it only to the authoritative `placeFacility` action. It accepts no client price, time, footprint, parcel, cells, validity bit, placement/facility/project ID, or quote token as law. Commit re-runs `queryPlacement()` against the current state before debit and identity creation.

Accepted response adds a TypeScript-authored receipt derived from the committed row:

```text
facility-placement-started {
  receiptId: `construction-started:${sessionId}:${commandId}`,
  placementId, blueprintId, facilityId, projectId,
  parcelId, origin, cost, weeklyOperatingCost, buildWeeks, completesWeek
}
```

The receipt must reconcile with the replacement snapshot. Exact replay of the same byte-identical `commandId` returns the original receipt/snapshot; Unity consumes `receiptId` once and never replays charge, sound, selection, or start animation. Reusing a command ID with changed payload fails with current `COMMAND_ID_REUSE` law.

On the first accepted response, the placement draft ends and selection becomes the exact numeric placed-facility/site ID from the receipt. The camera remains untouched; this is selection, not Focus. Exact replay or reconnect may restore/revalidate that selection but never applies a second selection transition.

For a current-state placement refusal, add structured `placementRefusal { request, quote }` to the existing authority-refusal envelope. For `STALE_REVISION`, session/protocol/schema mismatch, malformed input, or command conflict, omit it and force refresh/reconnect: an old footprint is not evidence of present illegality. Refusal never changes revision, cash, next ID, save, RNG, or event log, and the local draft remains.

`startConstruction` remains the parameter-free legacy Annex action. Never reinterpret it as generic placement. Move/demolish are deferred from P09A and later use their own parameterized commands with the same revision/idempotency discipline.

### B3.2 Completion witness

Project a narrow ordered witness from the permanent `constructionCompleted` Studio Event rows: `{ seq, week, kind, placementId }`, preserving the event's string placement ID, plus the log high-water mark. # P09A hostile-review acceptance summary

P09A fails if any of the following is true:

- a fresh campaign still begins on the mature lot;
- an existing or migrated save loses/reclassifies a building, Set, ID, placement, ledger row, reservation, or Theater;
- `INITIAL_PROPERTY` changes;
- Unity decides legality, affordability, duration, completion, capacity, identity, or migration;
- the legacy Annex command acts as a generic Build shortcut;
- the only way to build is a small memo or pixel-hunting ground;
- the player cannot understand why Development & Casting Office is first;
- preview, commit, and cancel are not distinct;
- invalid placement is color-only or lacks an exact reason;
- a stale commit spends or silently relocates;
- rotation exists only visually;
- site workers affect/imply speed without authority;
- construction is invisible or represented only by a timer;
- completion moves the camera, opens work, or auto-pauses;
- the completed facility loses the site’s exact identity/selection;
- one fixed construction root overwrites a second site;
- ordinary selection moves/demolishes a building;
- demolition hides refund, lost effect, or engagement consequence;
- Stage/Set/Production are collapsed;
- narrow/controller/reduced-motion play loses any fact or command.

P09A passes only when the Owner can truthfully say:

> “I founded a studio on almost nothing, understood the first business capability I lacked, chose where to invest, watched that exact building rise, and then used it to begin making a movie.”

Passing P09A does **not** seal the full Founding Flip. That later gate still proves reauthored Stage/Set-capable parcels, authoritative Builders affecting speed, screenplay/core-construction overlap, every required first-film facility, and bare lot → first film Greenlit → wrap.
