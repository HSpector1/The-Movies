**UI/UX WHOLE-GAME REVIEW PUBLISHED — FUTURE OPS REVIEW REQUIRED**

The delivered game already has much of the right interaction structure. Improve the connections and explanations within it. The strongest first change is to keep a production’s reason, consequence and response beside its persistent action. Then connect supported production remedies and people to their existing destinations, clarify campaign operations, and carry a consistent text-size choice between surfaces. These recommendations preserve the lot and the simulation.

The highest-confidence evidence is source structure, not measured player difficulty. Laboratory entry also has explicit Owner-reported friction. Casting comparison convenience is a lower-confidence design hypothesis. No game, editor, build, suite or native-input tool was run; no personal profile or campaign was accessed. No playtest, timing, hitbox failure, click-through defect or current visual crowding is claimed.

Read the [source and acceptance appendix](UIUX-WHOLE-GAME-REVIEW-SOURCES.md) for immutable locators, ownership checks and evidence limits. This is a proposed bounded pass for Future Ops disposition, not an execution order, acceptance reopening or a scheduled phase.

## Three reconstructed before / proposed-after flows

These are **source-reconstructed routes**, not observed behavior, measured click counts or new commands. Proposed steps remain DI/NVR.

**Flow A — understand and progress a production.** Before: select occupied Stage → Open Production → read state and blocker → scroll past operation explanation to worksites/company → Locate a worksite, or read remedy text and independently find its department → return. The pinned button can remain visible while its explanation is elsewhere. The stage route already identifies the exact holder; preserve it.

Proposed after: the same Stage or existing movie route → same production workspace → persistent strip reads `[film · current state] [real reason / next milestone] [existing action or waiting] [pending/result]`. A supported remedy opens its existing owner, carrying the film as return context. A company-profile excursion returns to the same detail position. Finishing and release remain their delivered transitions: release commitment is a deliberate decision and its result is inspected through existing result/History routes. Do not manufacture a “Resume filming” action for a locked film or promise a date from a conditional wait.

**Flow B — cast a lawful package.** Before: ready script → Casting → choose role → inspect candidates and pin comparison → compare → close comparison and find the candidate → set the draft → Review Greenlight → authoritative consequence review → commit. If short of talent, the existing Find an Actor / profession-filtered Roster path permits inspection, offer review and return. Camera tests provide evidence, not hiring or guaranteed availability. Those working routes are substantial and should survive.

Proposed after: retain that sequence of meaningful decisions; add an exact-candidate return from comparison and use the same labels/feedback hierarchy throughout. The role, pins, budgets and prior selections remain visible on return. The review still explains immediate commitment, ongoing costs and queued versus formed outcome. A stale candidate/quote requires fresh review; selecting a person cannot sign them. This is continuity work inside the existing workspace, not a new casting system or automatic talent optimizer.

**Flow C — keep a campaign before leaving.** Before: unnamed progress → Menu → Load/New/Quit → unsaved review → disabled naming instruction → Cancel → Save As → enter name → review any form-draft loss/overwrite → submit → generic saving message → accepted receipt. Named source and selected destination are different concepts already shown in Menu.

Proposed after: unsaved review → **Save As…** → existing naming/consequence review → operation-specific pending state → durable completion → explicit “Continue to [original task]” review using fresh authority. Cancel returns without spending, advancing or losing progress. A timeout means unresolved outcome, not failure with permission to issue a second operation. Retry uses the original request. Save As still activates a distinct copy; this interaction must explain that consequence.

## One control and navigation standard

Keep the lot as the normal home. Compact inspectors answer identity, state and next action. Casting comparison, Finance, Industry and campaign review earn larger workspaces. Local selection and global entries should converge on the same subject and authoritative facts, without requiring a world detour for every list action.

| Control | Keep / proposed standard |
| --- | --- |
| Select / inspect / Locate | **Keep:** selection is harmless; current stage entry and exact-ID joins. **Extend:** same inspector facts and explicit Open/Locate distinction. Locate frames the actual subject and retains a return origin. No automatic spending, contract, demolition or time advance. |
| Primary / secondary / destructive | One contextual primary verb. Open/Review means inspection; Confirm/Sign/Commit names a transaction. Keep costs and consequences before commitment. Back/Cancel is secondary and reachable; destructive controls remain distinct and explicitly reviewed. |
| Back / Escape / Cancel | **Keep:** top-layer menu → workspace → inspection → selection/origin grammar and existing casting discard review. Each act peels one layer. Back labels the destination where useful. Preserve draft, role, filter, sort, selected ID, scroll and camera on supported excursions; missing subjects explain their absence. |
| Focus and input | **Keep:** menu suppresses lower Toolkit input, workspace suspends camera, pointer-over-UI/gesture latch protects world input. Text entry owns typing/Enter; dialogs confine visible focus and restore the invoker. Verify mouse/trackpad and supported keyboard paths. Controller mapping is not physical-controller evidence. |
| Wheel / placement | Scroll the panel under the pointer without zooming the lot. Keep click/select placement plus keyboard nudges, real quote/footprint/reasons and explicit confirmation. Cancel an uncommitted preview without charge; after submission, do not label dismissal as cancellation of physical work. |
| State and response | Distinguish active work, ready decision, blocker, normal waiting and disconnected/unresolved state with words as well as color. Acknowledge input, disable duplicate submit, show authoritative success/refusal and retain a lawful retry. Never display optimistic Save completion. |
| Reading and help | Use consistent money/date/estimate terms, larger text, wrapping and reachable actions. Teach select → inspect → review → commit with short dismissible first-use guidance and a discoverable help route. Explain existing facts; no generated adviser inventing remedies. |

Attention policy: reuse current production attention, people’s highest-priority reason and Finance Upcoming routes. Routine progress is noninterruptive and grouped; action-needed items persist with their exact subject; imminent material deadlines receive prominence using real published dates. Group repeated symptoms by shared cause while retaining affected-film links. Do not add automatic pauses, fictitious forecasts or a new notification engine. Finance summaries must retain period/coverage/conditional-runway language; Industry must retain public disclosure and no private rival forecast. [S9–S11](UIUX-WHOLE-GAME-REVIEW-SOURCES.md#s9) identify the working foundations and native gaps.
