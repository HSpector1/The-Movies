**3. Formula soundness — MET WITH EVIDENCE.**
- Determinism/symmetry: confirmed structurally. Player `weeklyOverhead` (`economyView.ts:46-49`) uses `TUNING.OVERHEAD_BASE + TUNING.OVERHEAD_PER_EMPLOYEE * state.contracts.length` — the *same* constants `rivalWeeklyOperatingCost` uses (`hollywood.ts:106-111`). This is genuine evidence the player/rival fixed-cost comparison isn't apples-to-oranges.
- `baseMarketValue`: I checked whether the retroactive Lane F reach computation (dividing by "the" `baseMarketValue` at snapshot week W for a film released up to 52 weeks earlier) is well-defined. Confirmed via `worldgen.ts:671-679`: `baseMarketValue` is drawn once at world generation and I found no reassignment of it anywhere in the tick pipeline (only reads, in `tick.ts:704`, `hollywoodTick.ts:353`, `forecast.ts`, `reception.ts`, `agents.ts`, `filmPackage.ts`). It is a campaign-wide constant, so using the *current* value at snapshot time is identical to using the value at each film's release week — the formula is well-defined, though the charter's §2 doesn't cite this invariant explicitly. Non-blocking: recommend adding a citation to `worldgen.ts:673-679` establishing this before Wave 1 production, so a future reader doesn't have to re-derive it.
- Integer-tenths rounding, competition ranking (1-1-3), studioId tie-break, eligibility windows (`originWeek≤W-52`, `enteredWeek≤W-52`), and the running-film/window-edge rule are all internally consistent; the "6-week run always finishes inside the next window" claim is arithmetically correct for any release in `[W-52,W)` given `THEATRICAL_WEEKS=6` and 13-week quarters.
- One documented, not-obviously-a-bug incentive: Releases (`RELEASE_CAP=4`, counts *all* releases) and Films (mean of the *best* `FILM_CAP=4` scores) are orthogonal — a studio can pad Releases with weak films without it dragging down Films, since only the top 4 scores are averaged. This looks like an intentional quantity/quality split rather than a defect, but it's a genuine incentive worth the parent's awareness.
- Minor edge case, not blocking: `weeklyOverhead`/`weeklyFacilityOperatingCost` independently zero out during `state.founding !== null`; the band formula's "fixed cost of 0 → Thriving" fallback avoids a division-by-zero, but produces an odd (if rare and probably unreachable at W≥52) "Thriving" read for a still-founding player.
