# Late AQ publication lessons

These notes follow the fifteen lessons frozen in the AQ archive. Carry this whole finalization directory into the next checkpoint, as HANDOFF requires. These observations do not qualify a game run or repair the lost historical Git-metadata interval.

16. An approval must cover the exact artifact being published. The first publisher authenticated review bytes and checked an empty finding list, but could accept an archive-only review that explicitly excluded the staged index and current documents. Independent review caught this before any commit or push. Bind the review schema, decision, exact index receipt, archive manifest and changed document identities; do not infer scope from a successful-looking status.

17. Preserved evidence can contain meaningful whitespace that ordinary source checks reject. Actual index verification stopped on previously captured diff output, nested quoting, unnamed diff headers and historical context lines. Preserve the failed verification and original evidence. Any exception must be limited to authenticated archived bytes and demonstrated line shapes; continue requiring clean current documentation. Never trim historical evidence merely to make a publication check green.
