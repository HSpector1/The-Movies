# Independent pure observer-row controls

This is unrun source. The library exports `CASES` and `runObserverRowDiagnosticControls({createObserverRowDiagnostic, createM0FeasibilitySink, runObserverArm})`. The three dependencies must come from authenticated real source: the unchanged original public feasibility witness, and the pure diagnostic module whose same arm helper is used by the fullbody template. There is no test-side implementation of the arm's catch/finally logic.

The caller owns physical source/tool authentication, TypeScript type erasure of the standalone witness, module loading, recorded execution, output caps, process ownership and cleanup. This library imports only the native strict assertion module; it never loads a game graph, reads private data, starts a process, signals a target, or writes a file. Source preparation grants no execution authority.

Original witness authority is the 4,729-byte public `m0FeasibilityWitness.ts` with SHA256 `67ff5eb1005b5cfbc85ebdbd14e8e8dbb36fb0f2bed7ff484c617a9355512bf3`. Its original 512-row, 16,384-byte row, and 2,097,152-byte total limits remain the acceptance authority. Row bytes include the newline. Its native ten-field occurrence identity and row property order are used independently to construct boundary inputs and compare exact metadata. No witness implementation is copied into the library.

The API authority is root's R2 `API.md`, SHA256 `8b23588f28233794a7d0317b76d0770912015bc3ffd20dd823aae74b21225eb8`. Additional diagnostic-only unavailable ceilings are canonical UTF8 65,536 before parsing/reconstruction, scalar context JSON 65,536, reconstruction 524,288, 16,384 nodes/properties, and depth 64. These permit bounded unavailable metadata; they do not admit an original refused row or increase an observer cap.

Expected negatives require the exact original authoritative Error or an explicitly named diagnostic unavailable predicate. Setup errors, import failures, malformed result shapes, unexpected exceptions and incomplete cases fail the entire run. The sink spy observes the real original Error and invocation count; it does not substitute an authoritative sink. The only injected provider anomalies are finite, labelled unavailable controls. The real helper receives callback fault injections for exact Error precedence and cleanup order.

All shared-arm sticky cases originate with the actual witness's row-byte refusal E. They require E to survive a swallowed return, unrelated F, end failure, reset failure, both failures and writer failure. Cleanup always attempts end then reset. Reset deliberately clears factory state in these controls, so exact propagated E must have been retained locally. A successful arm returns its exact body value. The no-row group verifies the existing fatal cleanup precedence for ordinary F, end and reset errors.

`MATRIX.json` is the exact ordered case roster. A completed call returns schema `1370-observer-row-independent-controls-result/v1`, status `PURE_OBSERVER_ROW_DIAGNOSTIC_CONTROLS_COMPLETED_UNADOPTED`, exact case/positive/specific-negative counts and the full ordered results. Every result equals its matrix row plus verdict `ACCEPT_POSITIVE` for GREEN or `ACCEPT_SPECIFIC_REFUSAL` for RED. There are no skipped cases and no catch-all error-as-RED branch. The reported scope flags remain game false, privateM0ReadOrWritten false, fullQualificationAccepted false, executionAuthorization false.

The later recorded route must compare every result row and all counts, require actual child/recorder/tool exit zero and fresh scoped cleanup evidence, and distinguish worker output from recorder output. Passing these controls would qualify this public helper/witness interface only. Actual failed natural row metadata and fullfunction qualification still require a separately authorized measured route.
