## Four rights and read model

| Right | Law and owner boundary |
|---|---|
| R1 property | One event-derived current holder per StoryProperty. Whole-title sale belongs to P16B; live R3/R4 grants survive it. |
| R2 released film/library | One event-derived current holder per FilmId, independent of R1 and immutable creator. Whole-title sale belongs to P16B; no generic R2 licence. Active-run sale stays refused until a separate receipt-assignment producer exists. |
| R3 continuation | Default authority from current R1 holder, limited by scoped exclusive term licence. Not an independently sold title. P17 requests exact use/week. |
| R4 cross-media | Derived from relevant R1 property or R2 film title, subject to scoped exclusive/nonexclusive term licence; no executable grant before a real P18 consumer. |

The single future Licence schema carries ID, R3/R4, exact subject/use scope, lawful grantor/grantee, exclusivity, half-open `[startWeek,endWeek)`, consideration reference, expiry/reversion and source. P16A validates the empty migrated licence set and pure lookup/schema; P16B owns executable grant/consideration. Refuse unknown subject, overlapping exclusive scope/time, expired or over-wide grant and unlicensed sublicensing. No territory subdivision. A spin-off character/branch remains within the parent R1/R3 until an explicit P16 promotion mints a new property with parent provenance and preserved encumbrances. P17 supplies the payload and consumes title; it never mints or caches rights.

`libraryValuationV1(state,holderId,asOfWeek)` is a **pure as-of end-week** read. Require integer `0 <= asOfWeek <= state.market.tick`; reject future queries. Merge persisted and virtual title records by exact subject, require compatible equality if both exist, validate joins and `[0,100]` finite critic scores, then fold only genesis/events dated through `asOfWeek`. Include only films actually released through that week and R1 properties whose genuine/attested genesis is through that week. A historical `beforeCampaign` date precedes every nonnegative campaign week. A released R2 film held by `holderId` **at that date** contributes `Math.round(100000 * score / 100)`; each R1 property held then contributes `Math.round(25000 * maxQualityThroughDate / 100)`, with zero if no linked released film by then. The option premium is distinct from every R2 catalogue value; R1 and R2 may have different holders. R3/R4 grant value is zero in v1. Compute each per-item rounded value once in stable ID order, sum only safe integers, and return explicit unavailable on overflow, ambiguous provenance or unresolved terminal authority. Do not clamp a malformed score. These `$100,000/$25,000` coefficients are provisional tuning, not offer/clearing prices. Unreleased/shelved works get no film catalogue value. No cash, weekly revenue, Ranking/Standing, Legacy or reissue effect; book net worth, enterprise value, transaction price and auction price remain separate later models. Changing another use from virtual to materialized title cannot change this pure result.
