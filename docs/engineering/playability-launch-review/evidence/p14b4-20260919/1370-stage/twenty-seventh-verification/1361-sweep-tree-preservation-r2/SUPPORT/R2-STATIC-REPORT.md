# Independent static review — 1361 x2/x3 preservation r2

Decision: **ACCEPT for a bounded build and runtime verification**. This is a static design review, not proof that a produced archive passes. No bundle was built; no source, branch, or evidence file was changed.

Reviewed `build.py` SHA-256 `7fd06d6bd8555409d7e1bdefee3f2afce1731d8f1b4e23c8a99d21fdd04f1688` and `verify.py` SHA-256 `078130d2a23a50d2b4153056dfabaf2a8d2bda1afd185d9bbe0faa5be747c801`. Both actual source repositories remain porcelain-clean at the pinned private heads, have only the declared three refs, are unshallow, and have no unreachable objects reported by `git fsck --full --no-reflogs --unreachable`. Their local Git config contains no custom excludes path; each has the same seven ignored roots, 29 ignored entries, and 15 absolute symlinks into the live Movies repository.

R1 restoration concern is resolved in the r2 design. The builder pins ignored file types, modes, sizes and hashes, the exact `.git/info/exclude` bytes, all symlink texts, and the existing live-repository target types. The verifier audits every tar member against that inventory, rejects duplicate/unknown/unsafe paths, then restores a normal checkout from the assembled bundle in a temporary directory. It restores the exclude file and extras without following symlinks or overwriting tracked paths, and compares refs, HEAD/tree, clean ordinary status, ignored roots and full inventory, and symlink paths/targets. It checks the 15 external target paths before and after restore. It rejects Python optimized mode so its assertions remain active.

The self-contained history claim remains conditional on runtime proof: the verifier checks the bundle header for prerequisites, verifies against a new empty bare repository, clones from the bundle, and runs full `git fsck`. Bundle parts and the extras file are capped at 48,000,000 bytes; the verifier caps the exclude file too. The manifest accurately states that absolute symlink targets are external dependencies, so a relocated restore may retain link texts while losing live targets.

Build only while both exact source pins and inventories still match. The generated archive must pass r2 verification on staged bytes and independently retrieved remote bytes at a pinned evidence commit; record actual hashes and a complete restore receipt. Immediately before deletion, recheck each original source's HEAD/tree/refs, clean status, ignored inventory, links, and external dependencies. Delete only the two exact `tree` directories without traversing links, retain the sibling 1361 logs/patches and root sweep, and remeasure free blocks. A runtime failure or changed source means no deletion. The claimed 256,320 KiB gross source allocation does not establish net free-space recovery after archive storage and APFS sharing.
