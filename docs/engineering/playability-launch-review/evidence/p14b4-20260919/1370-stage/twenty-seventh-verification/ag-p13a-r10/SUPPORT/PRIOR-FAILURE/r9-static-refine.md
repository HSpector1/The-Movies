Date: 2026-10-07. This was static/read-only inspection of the frozen proposal, command file, r8 failed logs and prior evidence. No TS, Node, Vitest, game simulation, cache cleanup, or tracked edit was performed. No `ACCEPT_STATIC_CLEAN_ONLY` receipt was issued.

## Blocking finding

`runner.py` lines 32–52 define `inventory(root)` for the sealed package and skip any file whose relative path is exactly `MANIFEST.json`. `verify_mirror()` lines 62–66 calls that same function on the writable runtime mirror. Consequently a regular `runtime-tree/MANIFEST.json` can be added by the child and both the pre/post comparison and mirror digest still equal the authenticated arm inventory. The root of the mirror is deliberately writable for Vite. The claimed complete mirror inventory and rejection of all unexpected source writes therefore do not hold.

`runner.py` lines 250–259 also gates mirror postflight on `mirror.exists()`. If the child removes the mirror or replaces it with a dangling symlink, that block is skipped; a prior `STAGE_PASS` can remain accepted with no mirror postflight. If the child replaces it with a symlink to an existing directory, `remove_vite_config_temporaries()` iterates and unlinks through the symlink *before* `verify_mirror()` rejects the root. This can delete an exact-pattern file outside the output leaf. The cleanup itself can therefore escape the mirror.

The package/source `guard(manifest, 'post')` runs only after child exit zero and clean-artifact checks. The failure path compares the mirror if it still exists, but does not reauthenticate the sealed package, live source, external pins or remote HEAD. That cannot support an after-run source guard claim for a failed leaf. The current temp cleanup removes every matching filename without recording count, name, digest or size; its narrow regex matches the installed Vite filename, but it can erase an unexpected matching write without an audit trace.

For r10, separate the sealed-package self-manifest exclusion from the mirror inventory and compare **all** mirror members. Before any temp deletion, `lstat` the output leaf and mirror root, reject missing/non-directory/symlink roots, and make absence or replacement a recorded failure. Restrict temp cleanup to the exact nested-Vite pattern and expected cardinality, record each temp name/hash/size before removal, and reject any other drift. Reauthenticate sealed package and live source in a failure-safe `finally` path on both success and failure; record any guard error without losing the failure receipt. The revised path must run within the existing 300/330 and 720/750 deadlines. Rebind the new runner/manifest/command pins and obtain a new independent static review. Preserve r9 and r8 frozen.
