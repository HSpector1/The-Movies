# r10 AG adoption failed partial capture, archived

This package preserves the **failed** r10 AG adoption clean attempt `r10-ag-adoption-20261007-224614`. The original child exited 1 at its 1 GiB raw NDJSON capture guard; it did not time out and did not reach a 416-week clean admission. `DIRECT/RESULT.json` remains `STAGE_OR_GUARD_FAILURE`, and there is no `summary.json`. The archive contains 365 complete boundaries through week 364, including the exact 1,069,911,027-byte `boundaries.ndjson`.

The complete exact leaf is represented in Git by the three ordered `EVIDENCE.tar.xz.part-*` files. [SEGMENTS.json](SEGMENTS.json) gives each part's size and SHA-256 and the SHA-256 of their 113,296,808-byte concatenation. [SEGMENTS-README.md](SEGMENTS-README.md) gives the reconstruction command. The reconstructed `EVIDENCE.tar.xz` has a sorted 223-member inventory in `MEMBERS.json`; `MANIFEST.json` hashes the complete xz bytes, tar bytes, builder and direct failure receipts. The independent observed [review](REVIEW.md) and [receipt](RECEIPT.json) accepted **byte preservation only** after streaming every member, xz integrity testing and a deterministic rebuild. A separate independent segment review in `SUPPORT/` checked the three parts against that reviewed xz byte stream. The `SUPPORT/` directory also carries the static review, readback artifacts, build records and original failure audit. The prior 64 MiB archive attempt is preserved separately as a stopped operational attempt.

This package does not establish AG→E0G neutrality, a clean completion, 1363 closure or main promotion. The raw scratch copy may be removed only after remote publication and hash verification of this package; removing it does not change the failed result.
