# Independent static review — C0 serial mirror materializer r1

**Decision: REFINE, unrun.** The materializer authenticates Git blob OIDs, SHA/size-pinned overlay inputs, tree OIDs and a reviewed source manifest, but it does not verify materialized Git file modes. `write_archive` passes `0755` or `0644` to `os.open`; the inherited umask can strip bits, and the post-write check covers byte count and Git blob OID only. M0's selected tree contains a tracked `100755` executable test fixture. A stricter umask could produce a non-executable mirror while the result claims exact source materialization. In a versioned r2, set the mode with `fchmod` after creation, verify `stat.S_IMODE(fstat)` against the Git mode, and add a synthetic strict-umask/executable RED plus positive check. Preserve r1 bytes and do not build a real mirror from it.

A second blocker is receipt retention. `MATERIALIZE-RESULT.json` is written inside the disposable `OUT_ROOT/runId` mirror leaf, while the design requires deleting a successful mirror before the next arm and retaining authenticated receipts. The one-mirror guard rejects a prior leaf. Version r2 should place the durable result outside the disposable mirror, bind it to the leaf/run, and make the separately reviewed cleanup remove only verified mirror content.

The frozen manifest's four file hashes and sizes match, as do the accepted route inputs/design-review pins. Python compilation and tiny synthetic refusals pass. Source/review bindings are deliberately null until independent corrected full-source review, and the executable refuses absent hashes/status. The static path checks reject symlinks/traversal/collisions/nonregular Git or tar members; one-shot output, AC, 3.5 GiB preflight, 3 GiB floor, 160 MiB source cap and 900-second deadline are present. The materializer does not install dependencies, run a game or edit Git. The output/cleanup split needs the versioned correction above.

These are source-mode and durable-evidence refinements. It does not authorize a mirror build, types, 416-week route, protected neutrality or C0 attribution.
