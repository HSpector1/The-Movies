# Independent route-stop review — frozen C0 r8 observer and H/M0 source manifests

**Decision: REFINE_ROUTE_STOP.** Keep the r8 `ACCEPT_STATIC_PARTIAL` receipt as a statement about its bounded static/synthetic checks, but do not promote either arm's source manifest to `ACCEPT_STATIC_FULL_ERA_OBSERVER_ONLY` or build mirrors yet.

In both frozen market overlays, `proposalDraft` calls `m0Record(..., 'draftPrice', ...)` for the target subject at week 196/208. `m0Record` deliberately throws on row/total cap or serialization failure. The rival submission loop invokes `submitProposal`, which calls `proposalDraft`, inside a broad `try` whose `catch` converts any thrown `Error` to a `refusal` and continues. An observer cap/serialization error can therefore become a normal `SUBMISSION_REFUSED` outcome instead of stopping the diagnostic. The catch is at historical `advanceTalentMarketWeek` around lines 1551–1557 and modern around 1726–1735; the observed call is at historical line 320 and modern line 347. That violates refusal purity and can change the very proposal set/digests being measured.

A versioned fix must make an observer-originated failure escape the proposal catch unchanged, while preserving the existing handling of actual game proposal refusals. Add a focused RED that injects observer cap/serialization failure through the real `submitProposal` call and proves the route stops with no `SUBMISSION_REFUSED` conversion; test H and M0. Then independently review the corrected overlay and version new source manifests against its hashes. R8's 13-file static pins and six prior suites remain valid for their original narrow scope; they did not exercise this catch boundary. No mirror, full-era types or 416-week route is approved by this review.
