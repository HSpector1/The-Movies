# R5 full readback recorded launch rebind — unrun design

The accepted outer recorder r1 is precedent, but its r4 child and binding are tied to the preserved STOP. A fresh versioned r5 recorder must set an authenticated launch start and arm the 630-second whole envelope before reading bootstrap files. It must SHA-authenticate the standalone BOOTSTRAP.py by nofollow stable descriptor before spawning the child. BOOTSTRAP.py authenticates runner, SPEC, filled binding and static receipt, arms the remaining portion of the 600-second child timer before pinned reads, and executes runner bytes in memory. Run the child in a new process group under exactly one recorded heavy lane. The recorder waits for the actual child exit, sends TERM/KILL to any surviving group within the 630-second whole envelope, records child exit/timeout/groupClear and a one-shot fsynced receipt outside the mirror, and refuses a success-looking child output when child exit is nonzero or cleanup fails. The lane meta terminal line and recorder receipt must both be independently observed. AC, >=3.5 GiB preflight, >=3 GiB floor, clean production HEAD/src and exact remote refs apply before launch and after child.

This document is design only. `EXACT-LAUNCH-TEMPLATE.command` is bare source bootstrap and must not be run as the final route. Independent recorder static, filled exact, and observed reviews are required. Preserve earlier H typecheck STOP, addendum REFINE receipts and source-only classifications.
