On active expiry, nonzero exit, SIGTERM or SIGINT it terminates then kills the complete child process group and checks absence. Its finally block retains a separate hard SIGALRM for the **whole 210-second envelope**, including up to ten seconds for group cleanup and durable result. If the hard alarm fires, it sends KILL to the child group and writes an explicit STOP line to stderr; a missing or partial result is STOP. It does not claim success based on `lane-run.sh` wrapper exit.

A complete result is written as a bounded `.partial` file via a nofollow scratch/result dirfd, fsynced, linked into an absent one-shot final name, then the partial name is removed. The final file is reread by nofollow FD with SHA, size, mode, inode/path identity; the scratch root is reopened and compared to its original FD identity. If a deadline interrupts this operation, a partial file or missing final receipt is failure evidence and cannot be accepted as success. The result reports the real child exit and groupClear.
