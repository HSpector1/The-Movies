# Independent static review: H sandbox bootstrap/profile generator r4

Decision: **ACCEPT_SOURCE_ONLY_UNRUN**. I did not author r4. This accepts the bounded scratch source route as a candidate for an exact, separately reviewed real binding. It does not accept a real H profile, final profile canary, H control, type gate or C0 result.

R3's independent REFINE receipt `66b6d7999737a38da2125637fccc875d8946d4373555172bb67949cb67d3f6f3` proved a held output parent could move into a protected directory after the last pathname check. R4 starts `generate_profile.py` under an inline `sandbox-exec -p` default-deny-write policy. The unsandboxed parent builds that policy in memory and does not pass writable output FDs. The child keeps the r3 held nofollow/O_EXCL write and readback. In an ordinary scratch arm, profile bytes and policy SHA attest; in a same-policy moved-parent arm paused immediately before `openat`, the kernel returned EPERM and no protected profile appeared. Source/hash checks, pipe cap, 12-second child bound and group cleanup are present. The synthetic stop hook explicitly refuses real-mode bindings.

I inspected r3→r4 changes, bootstrap/generator/policy code and binding template, and independently ran `bootstrap_selfcheck.py`, `selfcheck.py`, `protected_red.py`, and `noisy_red.py`; all exited 0. This establishes tested source behavior on disposable paths only. No real H/dependency tree, heavy lane, Vitest or Git mutation occurred.

Exact review must bind a complete canonical protected set (production, H, evidence checkout if present, every accepted receipt parent, experiment/canary), resolved Python and local sandbox executable bytes, current Git refs, one-shot profile parent, full inline policy bytes/SHA and generated final-profile bytes/SHA. The template is unfilled. Real-mode profile generation must be followed by same-final-profile descendant deny/allow probes for each arm. The 12-second bound, policy cap, and source pins cannot be widened silently. An external local actor with privileges outside this child sandbox remains outside the synthetic proof; guard any real launch with pre/post path/source checks.
