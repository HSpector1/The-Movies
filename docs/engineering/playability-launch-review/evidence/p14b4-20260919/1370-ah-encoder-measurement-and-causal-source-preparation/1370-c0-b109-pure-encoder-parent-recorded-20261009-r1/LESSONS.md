# Lessons from the recorded encoder checks

Keep a failed success-path test measurable. The original two-second tiny Node wait failed and discarded its temporary streams. The reviewed test-only repair kept a single ten-second deadline starting before fork, retained bounded streams and parent stage timings, and preserved exact environment/output/exit/cleanup assertions. All fourteen tests passed; the measured child interval was 2.261721077 seconds. That supports the repaired test budget but does not identify a specific child startup substage or prove the earlier failure cause. Game and recorder deadlines stayed unchanged.

Use absolute measured costs to decide whether to retry. Eleven encoder control groups and 281 comparisons passed. The real indexed308 snapshot benchmark preserved bytes and fresh input purity; weighted encoder-only cost fell from 503.374290430 to 348.679256860 seconds, about 30.73 percent. The candidate still exceeds the shared300-second diagnostic bound before unmeasured work. A percentage improvement alone does not justify integration or another long run. Preserve the negative feasibility decision alongside the successful measurement. These are early-snapshot component timings, not a full runtime prediction.

Published checkpoint verification must read actual Git blobs as well as working files. The AG backup verified 1,269 payload files, 18 proposal companions and 97 prior Git references, then confirmed remote HEAD and ancestry. Preserve old proposals verbatim, but correct stale final status metadata in an explicit authoritative overlay. A later wording correction clarified that retained staff add payroll and overhead while avoiding severance; the net cash result itself did not change.

A documentation checkpoint changes HEAD and Git metadata even when gameplay source is unchanged. Record that transition explicitly for a pure test scope; never reuse an old full-production digest as proof of the new documentation. Separately accepted historical copies remain intact and are not rematerialized by implication.

Authenticate the evidence role before using a discovered scalar. A failed or exploratory trace cannot become an accepted historical measurement merely because its numbers match. Existing accepted modern inputs can support exact arithmetic only with a separately proved source, generation, initialization and call-order bridge to the historical route. Keep each measured and inferred role explicit.
