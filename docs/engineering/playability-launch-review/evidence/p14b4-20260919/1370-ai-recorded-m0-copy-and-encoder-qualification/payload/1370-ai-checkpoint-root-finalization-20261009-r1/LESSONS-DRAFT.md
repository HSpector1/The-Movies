# Lessons from this checkpoint

1. A recorder must preserve child streams and exit identity when validation throws. Empty exception strings need a nonempty fallback; they must never become apparent success. The new capture route isolated a fixture descriptor defect without retroactively assigning a cause to an older run whose diagnostics were lost.
2. Measure before another optimization. The pure profile places most measured work in traversal/emission and token joining. Its instrumented projection is distinct from an uninstrumented comparison and cannot pass a full game route. Use paired arms in the same process to test the next accumulation change.
3. Preserve reviewed originals before authorization changes. The exact six-file archive is the original package; current binding authorization is separately recorded, and its older PINS are historical.
4. A successful source copy has a precise roster. Its 1,675 Git source files plus five overlays yield 1,677 physical files. Missing bridge/dependency inputs belong to a separate types-ready contract; source-only success does not silently authorize type or game execution.
5. Reuse accepted scoped proofs while checking current facts. Preserve full guard equality across the freeze; refresh it after checkpoint Git mutations. Do not replay a historical run just because documentation HEAD changes.
