# AQ major lessons, revision 1

Independent test authors can invalidate an already accepted source review. Root initially accepted diagnostic R1, but the test author found that unknown codec exceptions still fell through to internal diagnosticCode handling. That could invoke a getter or falsely classify the exception. The original source and acceptance remain preserved; root explicitly withdrew that acceptance before runtime. A minimal R2 routes unknown exceptions at either codec operation directly to the generic fallback. A different reviewer accepted the corrected source. Never silently rewrite a review to hide a missed case.

Assertions inside callbacks that deliberately swallow errors do not prove their predicates. An affected control asserted diagnostic metadata inside the writer callback, where the real implementation intentionally contains writer failures. A failed assertion could be swallowed and the test still pass. Retain the observed line and a call marker, throw the intended writer error explicitly, then assert all metadata outside that callback after verifying the original error. Preserve the original control source and independent STOP; the fresh derivative keeps the same86-case roster.

Archiving old verification output preserves its formatting too. Whole late AO carry includes two diff-check stdout files whose literal plus-space lines quote original unified-diff context. The original index reader understood only the original blank context shape and stopped. The correction accepts only those exact manifest-authenticated logs and genuine authenticated unified-diff context, while retaining whole expected-set equality, every indexed byte, source-tree identity and clean current docs. Preserve both the failed reader and original output. Never normalize evidence to make a whitespace check green.
