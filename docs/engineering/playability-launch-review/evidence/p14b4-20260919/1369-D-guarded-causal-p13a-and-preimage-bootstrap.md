## Lessons carried forward

- A zero queue-wrapper exit is not evidence of a child pass. Check actual Node, recorder, timeouts, source pre/postflight, formal files, and process-group cleanup separately.
- Semantic types belong before a long clean route; the r2 narrowing failure was caught in 25 seconds rather than after a 416-week run. Preserve failed receipts and version the fix.
- Every prerequisite receipt needs an **exact required artifact set**, not a loop over whatever keys a caller supplies. Early drafts admitted `artifacts:{}` and caller-authored review files. Bind issued reviews and package hashes outside the package at launch.
- Full package membership includes nested files and symlinks. Python tools must use isolated startup (`-I`) and verify the package before imports; an unlisted `argparse.py` otherwise executes before a guard. The fresh recorder child needs the same protection.
- Stable ledger identity includes source-order occurrence; event IDs and raw array positions are compared as content. Era representation changes require an empty-era control before causal labels.
- Full historical preimages, not digest-only summaries, are required to locate the first changed protected field. The old employment hash predates approved aging behavior. Do not repin unexplained results.
- The protected adoption seed must be read from the pinned kit, not guessed from a phase label. Its original 300/330 timeout and later exploratory 720/750 route retain separate identities.
