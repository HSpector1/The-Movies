# Lessons after the AL checkpoint

- AL closed the real A208 control route, not the game ledger. Preserve that measurable win and use its exact observed admission when filling the next route instead of rerunning unchanged controls.
- A current operational authority must name its actual scope and published HEAD. The A208 guard amendment changes only its scope predicate and current identity comparisons; historical M0 completion stays historical.
- For the next encoder experiment, test the specific byte/refusal/trace failure of each deliberately wrong mutant. A generic failed process is not evidence that a classifier invariant was tested.
- A benchmark must name the encoders it actually times. Updating hashes without updating inherited arm labels and workload weighting can turn correct measurements into misleading evidence.
