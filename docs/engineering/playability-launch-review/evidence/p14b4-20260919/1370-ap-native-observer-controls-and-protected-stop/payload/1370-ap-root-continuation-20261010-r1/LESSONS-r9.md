# Major lessons from the AP observer repair

1. **Keep evidence complete; change its representation deliberately.** The earlier AO row occupied 17,305 bytes against a 16,384-byte limit because a 15,360-byte canonical JSON tuple was quoted again inside JSON. Context trimming could not solve it. Native tuples avoid that extra quoting while preserving the full canonical roundtrip, digest, context, ordering and multiplicity. The change explicitly amended expanded legacy accounting; unchanged physical caps do not mean the old textual accounting remained unchanged.

2. **Budget the payload and its wrapper separately.** An inclusive canonical depth of 64 needs a physical wrapper depth allowance of 66. Count each property once. Distinguish canonical overflow from a valid canonical payload inside an oversized physical row. Serialized-byte bounds do not establish a fixed JavaScript heap bound for arbitrary caller objects.

3. **Preserve the first failure by presence and identity.** Undefined, null and other falsy thrown values are still failures. Successful returns, later errors and cleanup cannot erase or replace an observer failure. Test cleanup with successful reset and successful end variants; otherwise a permanently failing cleanup can mask a broken precedence rule. A swallowed-error test must actually return normally, and an isolation test must first prove the old arm failed.

4. **Exercise the real consumer.** A test-side equality function proves only itself. The accepted controls reach the actual physical-envelope validator and the full evaluation-tuple comparison. Descriptor checks include symbols, nonenumerable properties and getters. A known-no-fit preflight and row-count refusal must not invoke caller getters.

5. **Make diagnostics work after failure without weakening acceptance.** Strict sticky-error checks initially prevented refused-row reconstruction. Pre-converting before capture would change refusal order; caching a failed payload could retain unbounded data. Two narrowly reviewed diagnostic-only codec methods share the bounded cores and are available only after the exact original row-byte error. They cannot clear the error, append evidence or accept output. Native parse errors preserve their actual identity.

6. **Treat every binding as executable.** Independent agents initially used inconsistent proposed review labels. A shared prospective protocol artifact eliminated that drift. Complete path replacement also missed a basename assembled with a directory at runtime. Review evaluated path constants, every accessed configuration key, and non-map recipe fields. Complete inverse proofs and valid syntax alone cannot establish agreement. Source-only findings included a missing historical reviewSchema and stale reader selector; they were corrected before launch and remain preserved as source findings, not game failures.

7. **Require only process identities the launcher establishes.** Pure controls guarantee PID equals PGID and record SID independently; their first reader incorrectly required all three equal. The fullfunction launcher separately enforces PID equals PGID equals SID before any launch claim. Readers must follow their own producer's actual contract. Record actual tool sessions, chunks and exits rather than predicting them.

8. **Separate historical proof, current protection and runtime success.** Historical AM types stay historical through the genuine AM-to-AN-to-AO commit chain. Fresh current protection does not repin old proof. A data-only adopter once expected actualSessionId where the authenticated receipt used sessionId; correcting that reader did not require rerunning a successful scan. Keep the original failed reader and its explanation.

9. **A passing boundary suite does not prove a full scenario fits.** Native controls passed all 72 cases: 13 positive and 59 specific refusals, including the original 18 ordering cases. Recorder time was 3.2204292549868114 seconds; independent review 93e6fcc6 and root adoption 401e54ce admit that exact result. Actual fullfunction session 17063 then generated the unchanged 12,428,510-byte fixture packet (0ae4a9a2) but failed the original row-byte limit after 58.333307976 seconds, without timeout. The mutant was not reached. This is a useful measured boundary, not a fullfunction pass.

10. **An unavailable diagnostic is missing evidence.** The new failure emitted only DIAGNOSTIC_UNAVAILABLE. It does not establish recurrence of the old AO row, its tuple size, promise family or fixture arm. The diagnostic recognized diagnosticCode but collapsed native codec code errors to a generic reason. That source gap suggests possible causes but does not prove the actual branch. The returned transform code/source maps were not retained and authenticated, so a transformed stack line cannot safely be mapped to a raw-source throw. The adopted next design reports a bounded lower bound of 16,385 when appropriate, never an invented exact size; successful reconstruction alone permits exact physical metrics. Limits, fixtures and the original error remain unchanged.

11. **Preservation checks do not fill in missing game proofs.** The mandatory full postflight passed after the failed scenario: the complete immutable map and nine strict roots match the genuine AO baseline, and nine owned PID/group checks report absence. Its 463.825130082987-second duration includes a 343.5372353630082-second inventory. Original M0 AFTER proofs, the Node terminal result and aggregate prefix/week claims remain null. A successful shared scan proves protection, not those missing game results.

12. **Backups require complete set equality.** At AO, normal staging omitted three ignored payloads until independent review compared the entire manifest-derived expected set with the index. Verify every expected path and indexed byte, including ignored evidence. Preserve authenticated unified-diff blank context whitespace and disclose its narrow warnings. A successful push with stale tracking calls for advertised-ref verification and explicit fetch, not an automatic repush. Carry all late publication and review receipts into the next archive. Raw whole-machine process/FD dumps and rebuildable caches remain local hash/size records.

Production gameplay source is unchanged. P16 remains incomplete; P17/P18 runtime and the 1363 ledger are still blocked. No native/Unity acceptance or main merge is claimed.
