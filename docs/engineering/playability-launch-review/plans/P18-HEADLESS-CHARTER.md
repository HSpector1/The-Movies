commissioned season, using an explicit P16 television grant and one distribution
agreement. This is the recommended first complete gameplay example because it
can exercise rights, staffing, weekly production, delivery and settlement without
requiring an endless renewal policy in the first checkpoint.

The example must reach an actual delivered work and reconciled settlement. A
registry, mocked right, synthetic delivery or unchanged film result with a new
label is insufficient. Before source release, resolve the applicable rows below
and pin the actual upstream implementations. No production unit, fee, audience
