# V2 — three finding corrections

This revision preserves immutable v1 source postimages, patch and manifest. Python SHA256 comparison verified every v1 postimage and original patch before preparing the new manifest. No repository writes, compiler, tests or runtime occurred. This revision is for targeted verification of the three reported findings, not evidence of gameplay acceptance.

1. **Market and Legacy concept ownership.** `marketIntegration.ts` now derives fresh carried authority only when an actual player release lacks an own concept. A fallback genre requires the production's exact current carried project ID, concept and in-production status. The actual ordinary market batch therefore receives its real genre before verdict. Current49 save descent explicitly forwards the already-derived authority to the shared-market validator and then to the private film bijection; a player film fallback requires its exact produced project. `campaignLegacy.ts` applies the same produced-film lookup. Live Legacy fact production derives authority; historical validator calls explicitly pass either the current era's context or null, so old reader defaults cannot derive fresh grants from raw payloads. No Hollywood concept collection is admitted wholesale, copied into player ownership or used as a general fallback.

2. **Safe early replay inputs.** `assertCarriedHistoryInputShape` precedes all new early history traversal, after the existing no-v6 early return. It checks only roots, rows and nested values immediately dereferenced by receipt replay and its native helpers: ledger rows, studio/release/closure roots, current/source development, employment terms, retained contract/production history, completion observations, decision IDs, native production snapshots and rewrite observations. It is a shape phase, not a replacement for frozen structural or current49 semantic validators. Missing roots/null rows/non-string decision IDs now have a `continued script: native production input ...` refusal before those accesses. The decision replay also explicitly checks a string ID before using string methods. No arbitrary TypeError is caught or converted to acceptance. All original final validators remain in place and older no-v6 histories retain their prior traversal.

3. **Immutable production provenance.** A greenlight receipt with a matching native active production now requires exact equality of the entire production row after normalizing only `remainingTicks`. That countdown must be integral, between 1 and its original value, and cannot consume more ticks than actual elapsed weeks. This binds budget, director, cast, craft, participants, writer, shape, promise, forecast and all other original fields. Cancellation retains the existing exact terminal snapshot join and elapsed-clock bounds. Release now also joins the actual film's director, participants and locked forecast benchmarks to the original greenlight, following the native conditional forecast-emission rule.

The mutable-field choice is source grounded: `Production` in `types.ts` has no mutable sound/technology fields; `operations.ts:1431,1614,1684,1764,1782` creates countdown-only replacements. Shooting progress and bindings are workflow fields. `technologyProduction.ts` writes the separate technology root. Native `actions.ts` writes the budget once at greenlight. The only other forecast replacement located is historical opening-band migration in `save.ts:7268–7288`, which cannot apply to a newly emitted v6 native production with a current full forecast. No new exception for budget, staffing, sound or technology was invented.

Only four files differ from v1: continuedScripts, marketIntegration, campaignLegacy and save. `V1-TO-V2.patch` isolates those corrections; the complete v2 patch includes all 24 postimages against the same exact 5a730f42 base. `DRAFT-MANIFEST.json` binds both patches and every postimage.

Required controls communicated to that author are numeric decision ID, null ledger row or missing consumed root, active budget/staffing drift against unchanged paid history, genuine release market assessment, Legacy fact consumption, and unchanged caller input after refusal. The original ten bodies and budgets remain unchanged here. No greenlight/cancel/release/save qualification is claimed.
