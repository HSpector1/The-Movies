## 4. Normal-person journey

1. Start on an accepted P08–P10 lot/profile copy.
2. Read literal Cash and signed current pace from the lot heartbeat.
3. Select Administration directly in the world; no rail/menu priming.
4. Read Cash, complete Weekly operating cost, Net weekly cashflow and a truthful Runway state.
5. Open retained Finance.
6. Reconcile opening Cash + every signed movement = closing Cash for the last complete recorded period.
7. Open Payroll and select one exact employee; reach the P10 Profile/contract owner.
8. Back returns to the same Finance filter/scroll/selection.
9. Open Studio Operations and select one exact facility; reach the P09 site/facility owner and optional Locate.
10. Open one exact film; distinguish Gross, received Studio Revenue, scheduled Studio Revenue and Projected/Final Film Contribution.
11. Review one P09 construction consequence showing capex now, Opex only when operational, capacity and current/future pace.
12. **Cancel: prove no committed domain action, no debit, no site, no employment change, no obligation, no save change. A read-only quote request may already have occurred; that session bookkeeping is not a failure.**
13. Reopen; deliberately commit through the owning P09 action; one exact receipt/site appears.
14. Return to Finance and see the actual capital movement while recurring cost remains unchanged until the facility becomes operational.
15. Advance to completion and verify operating cost begins on the advance after completion.
16. Save, load, reconnect and verify no duplicate payment, receipt or animation.
