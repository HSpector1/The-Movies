  presentation token. It creates no new `Screen`, App tree, Lot tree, renderer, or canvas.

  opens. A blocked or presentation-invalid handoff retains the accepted prior same-Lot/neutral law.

  adapters. Package content, evidence, legality, forecast, marketing, blocker, rejection, retry,

  animation/ambience may remain visible. There is one modal owner and one internal scroll owner.

  canvas node, camera, Screen object, and Casting-success world context.
- Custom Talent updates and autosaves the one App state without replacing the Lot, workspace,
  Assembly component, package draft, or step. Focus returns to the exact package control.
- A nested Profile makes both Lot and Package inert, owns focus exclusively, contains stale Lot
  callback tails, and restores the exact connected Package opener after close.
- Accepted greenlight keeps a noninteractive committed workspace until the exact successor reaches
  autosave, then atomically closes it and publishes one strict transient receipt to the already-
  mounted Lot.
- The Lot consumes that receipt once and exposes exact **PICTURE FORMED**, title, production,
  Director, Lead, complete company, phase, reservation, status, and countdown. Multiple-picture,
  stale, mismatched, delayed-renderer, and no-renderer cases never substitute another identity or
  replay the witness.
- Classic / Operation-Hollywood-off retains the established standalone Assembly route. The V1
  same-mounted guarantee is deliberately narrow to the accepted Operation Hollywood Lot-native
  Casting handoff.
