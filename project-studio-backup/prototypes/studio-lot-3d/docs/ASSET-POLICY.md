# Asset Policy — Meridian 3D Vertical Slice

## M1 (gray-box) — current
All geometry is **primitives** (box/cylinder/cone/capsule/plane) authored in code
with muted placeholder materials. No external asset files. Nothing here is final art;
per the milestone, beauty is not judged at M1.

## Permitted (from M2 onward, when Gate A passes)
Assets licensed **CC0 / MIT / BSD / Apache / CC-BY** (attribution documented) — or
another clearly permissive license with a written compatibility note. One coherent
**primary visual family** for generic architecture/vehicles/props/vegetation/
characters; secondary assets only if materially restyled to match.

## Not permitted
GPL/AGPL art or code as runtime material; ripped game assets; assets from *The
Movies*, Zoo Tycoon, or RollerCoaster Tycoon; reverse-engineered/decompiled content;
NOCD repos/executables; unclear-license assets; AI-generated 3D assets without clear
commercial provenance; real studio logos/landmarks; purchased packs (no paid
purchases in the initial survey — a recommendation may be made later).

## Must remain original / substantially custom
Meridian gate, administration landmark, crest, water tower, flagship soundstage
identity, screening-theater identity, hero backlot façade, production signage,
recurring Deco trim, signature red + brass language.

## Approved concept package
`~/Desktop/Meridian Pictures Art Direction/02 Concept Brief/renders/` is the
**art-direction target only** — reference for form/palette/scale. Concept renders
are **never** used as runtime textures, traced geometry, or billboard backgrounds.

## Provenance
Every imported asset gets a row in `PROVENANCE.md` (source URL, license, files,
attribution, restyle notes) before it enters the scene.
