# Licenses

License evidence for third-party runtime assets that were included in the backup.

## 3D visual spike — Kenney CC0 GLB kits

The 3D spike ships 7 runtime `.glb` files under `public/m2-assets/`. All are from
Kenney (www.kenney.nl) and licensed **Creative Commons Zero (CC0)** — public domain,
no attribution required. The original `License.txt` from each kit is preserved here:

| File | Kit | Runtime GLBs |
|---|---|---|
| `3d-spike-kenney-cc0/car-kit-License.txt` | car-kit | `delivery.glb`, `sedan.glb` |
| `3d-spike-kenney-cc0/character-License.txt` | character | `character-a.glb` |
| `3d-spike-kenney-cc0/city-License.txt` | city | `building-a.glb` |
| `3d-spike-kenney-cc0/factory-License.txt` | factory | `box-large.glb`, `structure-tall.glb` |
| `3d-spike-kenney-cc0/nature-License.txt` | nature | `tree_default.glb` |

Source: `~/The Movies - 3D Visual Spike/public/m2-assets/<kit>/License.txt` at `591f3aa`.
