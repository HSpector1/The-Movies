# Project: Studio Audio Foundry Audition Desk

This tracked directory is the small reproducibility source snapshot. Generated `dist/`, `public/data/`, audition audio, and `node_modules/` stay outside Git. The Owner-ready prebuilt copy is packaged under `/Users/bruce/Desktop/Project-Studio-Audio-Return-Package-01/AUDITION-APP/`.

This is a local-only Owner audition tool for `PROTOTYPE_READY_FOR_OWNER_AUDITION` music and `RADIO CONCEPT PROTOTYPE` reels. It does not establish approval, rights clearance, or production-import authority.

Launch `START-AUDITION.command`, then open `http://127.0.0.1:8765/`. The catalogue contains 27 provisional picks, 27 alternates, and three radio concept reels. Ratings persist in local browser storage and export to CSV or JSON. In blind mode, the local identity record remains concealed until a keep/maybe/reject verdict is saved and the Owner chooses **Reveal family**. The server binds only to loopback. The app has no account, cloud dependency, telemetry, or private token.

Build source uses the Sites scaffold. The delivered app is the prebuilt `dist/client/` tree served by Python; normal audition use does not require npm or network access. Its audio folder contains audition derivatives only: AAC music previews, primary-pick seam checks, and AAC radio previews. It contains no raw generation.
